# Task 01：ANWEN 追加 Splice Detection

## 文件
- `change-request.md`：模拟变更请求
- `submission-template.md`：提交模板
- `answer-key.md`：标准答案（页/设备/端子/电缆/IO/BOM）
- `bom-diff.csv`：BOM 差异
- `base-anwen-focus.pdf`：ANWEN 起始页（PDF 69–76、149、175、182、184）
- `target-azaria-focus.pdf`：AZARIA 目标页（PDF 69–76、150、176、183、185）
- `target-spd-page-750.pdf`：目标 SPD 单页
- `before-anwen-pdf72-vel721.png`、`before-anwen-pdf73-rls1015.png`、`answer-azaria-pdf73-spd750.png`

## 用法
1. 打开 `change-request.md`，确认任务。
2. 打开 `base-anwen-focus.pdf` 和 `target-azaria-focus.pdf` 对照。
3. 在 EPLAN 中打开 ANWEN 源项目改图；如果只有 PDF，打印/标注起始页并写变更清单。
4. 按 `submission-template.md` 提交。
5. 用 `answer-key.md` 自评，或交给师傅按评分表打分。

## 注意
- 这是用真实项目构造的训练任务，不是真实发生的变更单。
- 只评 SPD 相关页/器件/端子/电缆/IO/BOM；宽度、客户、其他选配差异不在本题范围。
- 目标图纸是 AZARIA 的真实导出页，不是人工绘制的答案。
