横切机（Cut-off，图纸代号 NQ/HQ）把连续运行的瓦楞纸板按订单长度切成单张。它决定切长精度、换单损失和整线产能。新员工先建立这张“整线位置图”，后面看图纸才不会迷路。

## A 它在整线的位置
```flow LR
原纸架 -> 单面机 -> 天桥 -> 预热/涂胶 -> 双面机
双面机 -> 纵切压线 -> 横切HQ -> 堆码AS -> 物流
```

| 上游 | 本机 | 下游 |
|---|---|---|
| 双面机出来的是连续纸板，速度与温度已稳定 | 按订单切长切断，双刀机型可不减速换单 | 堆码机按订单/托盘分批堆叠 |
| 纸板速度、楞型、克重影响切长与刀辊同步 | 切长、切口质量、废品剔除 | 堆码节拍反过来限制横切产能 |

## B 横切机的三个任务
| 任务 | 说明 | 电气关注点 |
|---|---|---|
| 定长切断 | 按订单切长 L 切断纸板 | 编码器、刀辊同步、切长补偿 |
| 换单 | 新订单切换切长/速度，双刀上下纸路可各切一种 | 订单管理、AOC、双刀交接 |
| 质量与废品 | 接头、坏板、试机板剔除 | 拼接检测、废料翻板、Good Cut 信号 |

## C 机型谱系：先看单刀还是双刀
| 机型 | 结构 | 图纸中的功能组 | 26 份图纸中的份数 | 页数范围 |
|---|---|---|---|---|
| SQ-M+ | 单刀（Simplex），1 个横切单元，2×112kW 主电机 | `==HQ1` | 7 | 233–252 |
| SQ-M | 单刀，柜号 13515/13545，1×55/90kW + 2×15/35.4kW | `==HQ1` | 3 | 184–203 |
| SQ-N | 单刀，柜号 13511 起，精简平台 | `==HQ1` | 6 | 144–190 |
| HQ-M | 双刀（Duplex），2 个横切单元；新老两套柜号 | `==HQ1` + `==HQ2` | 10 | 335–421 |
| KQ-M | 旋转剪切（KQ），不是横切单元 | `==KQ` | 4 | 61–80 |

> SQ、HQ、N、M、+ 的字母全称没有出现在资料中。上表按图纸结构和 SV 的 Frame 字段（Simplex / Duplex 925）分类，不按字母猜含义。

```tree
一份 SQ-M+ 图纸
  ==GEN Generally
    =MPS 供电
    =LVS 400VAC
    =DCV 24VDC
    =ACV 230VAC
    =STE 安全
    =PLC PLC
    =DEX 信号交换
  ==HQ1 Cut off 1
    =INF 进料
    =KNB 刀梁
    =OUS 出料
    =WEV 废料
    =JAM 卡纸
```

## D 双刀与单刀的差别
| 维度 | 单刀 SQ-M+ / SQ-M / SQ-N | 双刀 HQ-M |
|---|---|---|
| 横切单元 | 1 套（HQ1） | 2 套（HQ1 + HQ2） |
| 换单 | 降速或停机换单 | 两套机组分上下纸路，各切一种切长，减少换单损失 |
| 图纸功能组 | 一套 INF/KNB/OUS/WEV/JAM | 每套各有一组，页码成对 |
| 主传动 | 1 套上刀辊，2 台电机；下刀杆机械联动 | 2 套上刀辊，每套 2 台电机；下刀杆机械联动 |
| 典型项目 | AISLING、ANSEL、ANWEN、AZARIA、BRISEIS、GUNN、AUDRIC | ALARIC、ARAMIS、ARLEN、DALIAH、SAANA |

> “2x45kW / 2x112kW”表示一套上刀辊两端各一台电机；下刀杆机械联动。双刀机型有两套上刀辊，共 4 台主电机。

> 新平台例外：SQ-M 是 1 台 55/90kW 模块带 2 台 15/35.4kW 电机；SQ-N 紧凑型是 1 台 55kW 带 1 台 53kW；新 HQ-M 改用 Lenze 9400。不要用旧公式套所有机型。

## E 一台 HQ 的物理组成
```tree
HQ 横切机
  机架 Frame
    Simplex / Duplex 925
  进料 Infeed
    双辊进料、EP 自动、压力调节
  刀梁 Knife bar
    上刀辊（2 台电机）+ 下刀杆（机械联动）
    钢刀梁 / CFK 碳纤维刀梁
    双齿/后倾刀
  出料 Outfeed
    双电机出料、间隙控制、出料站
  辅助
    废料输送、油泵、冷却、卡纸检测
  电气
    单刀 SQ-M+ 柜 13501 / 13511 / 13531 / 13541
    单刀 SQ-M 柜 13515 / 13545
    单刀 SQ-N 柜 13511 / 13531（部分只有 13511）
    双刀旧 HQ-M 柜 13505 / 13515 / 13525 / 13545
    双刀新 HQ-M 柜 13501 / 13511 / 13531 / 13541
    操作箱 13715（旧）/ 13700（新 HQ-M）
    主传动、Beckhoff PLC、安全模块
```

## F 订单视角的十个配置维度
| 维度 | SV 字段示例 | 影响 |
|---|---|---|
| 机型 | HQ-M / SQ-M+ / SQ-M / SQ-N | 单刀/双刀、图纸页数 |
| 幅宽 | 2500 / 2800 / 3350 mm | 机架、刀梁、出料、柜体 |
| 操作侧 | Left / Right（图纸 LHD/RHD） | 柜体与操作箱位置、现场布线 |
| Placement | 1 / 1+2 | 横切单元在整线的布置 |
| 切长图 | HQ V02/WW2500/45KW/STEEL1500 | 主传动功率、刀梁材质 |
| 主传动 | 2x45kW 异步/刀 / 2x112kW 同步 | 驱动选型、冷却、柜体 |
| 刀梁/刀辊 | Steel 1500 / CFK 1800 g/m² | 惯量、加减速、电机选型 |
| 框架 | Simplex / Duplex 925 | 单刀/双刀 |
| 进出料 | Twin-roll / EP / Outfeed station | IO 点、电机、气动 |
| 电气标准 | EU / CN，柜冷 water/air | 元器件标准、认证、柜体冷却 |

> 新平台还有 SQ-M 1×55/90kW、SQ-N 1×55/2×90kW、新 HQ-M Lenze 9400 2×45/60kW 等配置，详见 [08 矩阵](08-project-matrix.html) 与 [19 驱动](19-drives-motors.html)。

## G 新手最容易搞错的六件事
| 错误认知 | 事实 |
|---|---|
| SQ-M+ 就是双刀 | SQ-M+ 在 26 份图纸中都是单刀，只有 HQ-M 出现 HQ2 |
| 同机型配置一样 | 同为 SQ-M+，幅宽可从 2500 到 3350，主传动可从 2x45kW 到 2x112kW |
| 图纸页数多就配置高 | 页数受双刀、选配、报表和语言影响，不能直接比较 |
| 2x112kW 是两台横切机 | 是一套上刀辊两端的驱动电机；下刀杆机械联动 |
| KQ-M 也是横切机 | KQ 是旋转剪切，图纸功能组是 `==KQ`，没有 HQ1 |
| LHD/RHD 只是左右手 | 它决定操作侧，直接影响柜体和现场布线 |
