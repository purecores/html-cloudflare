先看站，再看页，最后看端子。地址对了，线不一定对；端子对了，程序不一定对。

## A 三条地址规则

| 规则 | 正确做法 | 常见错误 |
|---|---|---|
| PLCV 页 = 站内位置号 | K202 → EPLAN 202 / PDF 126 | 把 PDF 页当卡号 |
| 卡号 ≠ 物理顺序 | K3 在 K140 后面 | 按 K 号排模块 |
| 地址会跳号 | I100/I102/I104 | 上一个模块加 1 |

```flow LR
现场传感器 --> 端子 -X --> 电缆 -W --> EL 模块 --> PLC 地址 --> PLCV 页 --> 程序
```

三条完整链路：

| 类型 | 现场 | 端子/电缆 | 模块/地址 | PLCV |
|---|---|---|---|---|
| DI | `-531S2` | `-XHQ:15` / `-WC666` / `-XCCC:15` | K100:1 / I100.0 | 100 |
| DO | `-1015Q1` | `-X531:10` / `-503WC1` / `-X511:10` | K202:9 / Q102.8 | 202 |
| AO | `-1195K5` | `-XEP2` / `-1195WC3` | K400:AO0 / PQW140 | 400 |

> `-401A1` 是 IPC 站。`-405A1` 是 I/O 站 1。`-406A1` 是 I/O 站 2，只有 HQ-M 双刀项目才有。
>
> KQ-M 另有一套 PLC 视角：ALARIC KQ 有 `&PLCV` 19 页（IM155、F-DI/F-DO、DI/DO、IO-Link、AI Energy Meter）；ANDREAS/ROCH/SAMANTHA KQ 没有独立 `&PLCV`，PLC 可能在 HQ 柜或不在 KQ 范围。不要把 HQ 的 K107/K208 地址套到 KQ。

```tree
-401A1 | C6015 IPC
  405A1 | I/O 站 1
    K1 | EK1100 耦合器
    K10 | EL1918 8DI 安全
    K20 | EL2904 4DO 安全
    K100 | EL1409 16DI
    K400 | EL4074 4AO
    K500 | EL5102 2 编码器

    K502 | EL5102 HQ2
-427K1 | CU320-2 主传动
-1100T1 | i950 辅助伺服
```

| 设备 | 角色 | 接口 |
|---|---|---|
| C6015 `-401A1-K1` | HQ 主控 | LAN1 PROFINET；LAN2 EtherCAT |
| EK1100 `-405A1-K1` | EtherCAT 耦合器 | X1 进 / X2 出 |
| CU320-2 `-427K1` | 主刀辊传动 | EtherCAT X1400；PROFINET X150；DRIVE-CLiQ |

| 器件 | 站 | PLCV 页 |

## C DI：16 个端子不等于 16 个通道

| 模块 | 地址 | 通道 | 真实用途 |
|---|---|---:|---|
| EL1409 K100 | I100.0–15 | 16 | 面板/油压 |
| EL1409 K102 | I102.0–15 | 16 | DF/反馈/堵纸 |
| EL1409 K104 | I104.0–15 | 16 | 激光/冷水机/反馈 |
| EL1258 K140 | I140.0–7 | 8 | 剪切脉冲/有纸/铝箔 |
| EL1918 K10 | I200.0–7 | 8 | 安全门 |
| EL1904 K11–K13 | I201–I203 | 4×3 | 急停/LOTO/刀架 |

安全端子的位序不按端子号：

| 模块 | 端子对 → 过程位 |
|---|---|
| EL1904 | 1/2→bit0，5/6→bit1，3/4→bit2，7/8→bit3 |
| EL1918 | 1/2→bit0，9/10→bit1，3/4→bit2，11/12→bit3 |

> EL1258 的端子 1–8 是 DI。端子 9–16 是 +24V。V3.3 的 `16DI_I140` 不是 16 个接线点。

DI 链路：

```flow LR
-531S2 --> -XHQ:15 --> -WC666 --> -XCCC:15 --> K100:1 --> I100.0
```

现场多为 PNP。传感器给 +24V，0V 公共。标准 DI 约 3 ms 滤波，EL1258 带 1 µs 时间戳。

## D DO：0.5 A 只能驱动继电器

| 模块 | 地址 | 典型负载 |
|---|---|---|
| EL2409 K200 | Q100 | 灯/AOC |
| EL2409 K201 | Q101 | 面板灯/进纸阀 |
| EL2409 K202 | Q102 | 油泵/主接触器/润滑 |
| EL2409 K204 | Q104 | 激光/快停/钢刷 |
| EL2904 K20 | Q200 | Stop-Safe/STO |

DO 链路：

```flow LR
Q102.8 --> K202:9 --> -X531:10 --> -503WC1 --> -X511:10 --> -1015Q1 --> -1010Q3/Q4
```

> Q102.8 不直接带主接触器。它先带 24V 中间继电器 `-1015Q1`（3RT6016）。继电器触点再带 220VAC 线圈 `-1010Q3/Q4`。

| 方式 | 实际例子 |
|---|---|
| 中间继电器 | `-1015Q1` |
| 光耦 | Q102.9/10 到 KQ/RD |
| 电磁阀 | `-1090Y1/Y2` 进纸辊升降 |
| 比例阀 | `-1195K5` 压力给定 |

> EL2409/EL2809/EL2904 都是每通道 0.5A。感性负载要续流。模块总电流要看手册。

## E AI/AO：每个通道占两个字

| 类型 | 模块 | 地址 | 样本 |
|---|---|---|---|
| AI | EL3002 | PIW120/122 | 0 套实装 |
| AO | EL4074 K400 | PQW140/142/144/146 | AISLING 压力 |
| AO | EL4074 K402 | PQW160/162/164/166 | ARAMIS HQ2 |
| AO | EL4002 | PQW150/152 | 仅矩阵 |

| 基地址 | CH00 | CH01 | CH02 | CH03 |
|---|---:|---:|---:|---:|
| PQW140 | 140 | 142 | 144 | 146 |
| PQW160 | 160 | 162 | 164 | 166 |
| PIW120 | 120 | 122 | — | — |

量程：

- SR Speed：0–20mA / 0–500 m/min。EL4074 出 0–10V，外部转换器变 0–20mA。
- 压力：0–10V 对应多少 bar 由阀定。图纸没给，待确认。
- AI 0–10V 没有断线检测。4–20mA 要转换器或电流模块。

AO 链路：

```flow LR
PQW140 --> K400 AO0 --> -XEP2 --> -1195WC3 --> -1195K5 --> 压力
```

> EL4074 只给 0–10V 给定。阀的 +24V/GND 由 `-X24V` 供给，不是模块输出。

## F 编码器：4096 线 TTL 与脉冲分配

| 通道 | 用途 | 实际 |
|---|---|---|
| EC_130 | 测量辊 HQ1 | `-1171B1` 4096 TTL |
| EC_132 | 刀辊 HQ1 | `-1380B1` 经 IV-30 |
| EC_150 | 激光 | `-701U1` |
| EC_152 | 预留 | 未用 |
| EC_160/162 | HQ2 | ARAMIS |

```flow LR
-1171B1 --> -1171U1 --> -1171WC1 --> K500:1/9/2/10/3/11/5/6 --> EC_130
-1380B1 --> -721K1 IV-30 --> K500 EC_132
-721K1 IV-30 --> CU320-2 CH2
```

> EL5102 模块侧每通道 8 个信号。EPLAN 的连接器符号有 16 个引脚（含 DI/Latch/Gate）。电缆用 `PAAR-TRONIC-CY 4×2×0.5`。屏蔽接 `SH`/PE。

> `-721K1` 是 IV-30，1 进 6 出。它是脉冲分配器，不是分频器。分频在驱动或 PLC 里设。

## G 从矩阵到订单：差多少、改什么

| 项目 | 模块 | 容量 | 标准 DI / DO | AO |
|---|---:|---:|---|---|
| V3.3 | 40 | 422 | 11×EL1809 / 11×EL2809 | 4×EL4074 + EL4002 |
| AISLING | 16 | 152 | 3×EL1409 / 4×EL2409 | 1×EL4074 |
| ARAMIS | 21 | 206 | 4×EL1409 / 6×EL2409 | 2×EL4074 |
| AUDRIC | 16 | 178 | 4×EL1409 / 5×EL2409 | 0 |

重复模块名要用“型号 + 地址”区分：

| 名称 | 安全 | 标准 |
|---|---|---|
| DI5 | EL1904 I204 | EL1809 I100 |
| DI6 | EL1904 I205 | EL1809 I101 |
| DO2 | EL2904 O201 | EL2809 O100 |
| AO1 | PQW140 | PQW160 / PQW170 |

Option 裁剪：

| Option | 加什么 | 样本 |
|---|---|---|
| HQ2 | DI/DO/AO/编码器 + 406A1 | ARAMIS |
| CMC | 1×EL1409 + 1×EL2409 | 无 |
| 真空 | EL2409；比例加 AO | ARAMIS/AUDRIC |
| Fanfold | 2–3×EL1409 | 无 |
| 门锁 | DI + DO | 无 |
| 激光 | EC_150 + DI + DO | AISLING/ARAMIS |
| 客户接口 | DEX 端子/光耦 | 三个样本都有 |
| 安全中心/EU | +EL1904 +EL2904 | 无 |

增加/删除 IO 的检查表：

1. 先定信号类型和电平。
2. 再数通道，留 10–20% 余量。
3. 选模块，核对型号和物料号。
4. 分配地址，保持站内位置号。
5. 改 EPLAN：PLCV/WDA/端子/电缆/BOM/图例。
6. 改 PLC/HMI/安全程序，重做安全验证。

常见错误：

- 按端子号推安全位号。
- 把 O 当 Q。
- 把 EL1258 当 16DI。
- 模拟量只读基地址。
- 把 EL4004 当 EL4074。
- 把 V3.3 地址直接抄。

> 待确认：EL4004/EL4074、EL1904/EL2904 物料号、图例行错位、Good Cut 未检索到。下单前按 BOM 和电路页核对。

> 新平台差异：新 HQ-M（ADARA/BELEN/ROCH）的 `=PLC` 约 22 页（+13511），驱动改为 Lenze 9400；旧 AISLING 的 16 模块/152 通道不能直接套。新项目先看 PLCV 页段和柜号，再对 V3.3 矩阵。

> 为什么是十几二十个模块、每个模块接哪些信号，见 [39 Beckhoff 模块与信号](39-beckhoff-modules-signals.html)。
