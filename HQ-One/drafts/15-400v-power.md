400V 侧只看三件事：电从哪里来、经过哪些保护、到哪里去。本页用三个真实项目，把这三件事串起来。

## A 先看结论
```kv
单刀主链: 400V → -10Q1 630A → -51U1 → 400A → 200kW → 250kW
双刀主链: 400V → -10Q1 400A → -51U1 → 160A → 110kVA → 125A → 132/110kW
辅助 400V: -51U1 → -52F / -53F / -56F / -81F
预充支路: 25A → 11kW 接触器 → 3×20Ω → 直流母线
```
```callout info 一句话
AISLING 没有主变压器；ARAMIS/ALARIC 有 -51T1 110kVA。主接触器在单刀里叫 -61Q3/-61Q5，在双刀里叫 -61Q1/-62Q1。
```

## B 进线 =MPS 与 PE：客户 400V 怎么进来
```flow LR
(客户 400V/50Hz) -> [-10Q1 主开关] -> [-51U1 主母排]
[-51U1] -> [单刀 -51F1/F2 400A] -> [-61Q3/-61Q5 200kW] -> [-1300T1/-1302T1]
[-51U1] -> [双刀 -51F1 160A] -> [-51T1 110kVA] -> [-58U1] -> [-58F1/F3 125A] -> [-61Q1/-62Q1]
```
| 项目 | 主开关 | 主进线 | PE | 负载/备用熔断器 |
|---|---|---|---|---|
| AISLING | 630A `OT630E03` 851209539 | 3×2×150 + 2×120 mm² | `-10U3` 9 端子 | 382kVA / 3×630A |
| ARAMIS | 400A `0T400E30` 170431750 | 3×120 + 120 mm²，40m | `-10U3` 9 端子 | 130kVA / 3×250A |
| ALARIC | 400A `0T400E30` 170431750 | 3×120 + 120 mm²，40m | `-10U3` + `-10U4` | 130kVA / 3×250A |

| 端子/母排 | 作用 | 关键接法 | 页 |
|---|---|---|---|
| `-10U3` | 主 PE 母排 | 进线 PE、各柜 PE、`-51T1.PE` | `10 / PDF 9-10` |
| `-XPE` | 柜内保护接地 | 控制变压器 PE、驱动 PE、PLC PE | `12 / PDF 10` |
| `-XPER` | 外部/导轨保护接地 | 现场小负载、导轨 PE | `12 / PDF 10` |
| `-XPEN` | 柜间 PE 转接 | 13501 ↔ 13511 | `26 / PDF 12` |
| `-10U4` | 设备框架 PE（仅 ALARIC） | 50mm² GNYE 到框架 | `10 / PDF 10` |

- 主开关端子 1/3/5 进，2/4/6 出；`-10Q1` 是隔离开关，不是断路器。
- AISLING 进线只在 `=MPS 10 / PDF 9` 画了截面，`&WRE` 未列长度。
- ARAMIS/ALARIC 在 `&WRE 10 / PDF 203/191` 写 `Customer provide Cables`，参考长度 40m。
- `-WP13001..03` 是相线，`-WP13004` 是 PE；AISLING 每相两根 150mm² 并联。
```callout warn PE 截面规则
主保护导体最小 10mm²。XPE 的 2.5mm² 是控制变压器分支 PE，不是主 PE；XPER 的 6mm² 只服务外部小负载。
```

## E 主传动供电：预充、主接触器、母线、电容
```flow LR
(400V 母线) -> [主熔断器] -> [主接触器] -> [驱动 L1/L2/L3]
(400V 母线) -> [25A 熔断器] -> [预充接触器] -> [3×20Ω] -> [直流母线]
[直流母线] -> [15 000µF 电容]
[直流母线] -> [放电接触器] -> [200Ω/400W]
```
| 器件 | 单刀 AISLING | 双刀 ARAMIS/ALARIC | 作用 |
|---|---|---|---|
| 预充接触器 | `-1010Q3/Q4` 11kW | `-1000K3` 11kW | 串电阻充电 |
| 预充电阻 | `-1031A1/-1032A1` 3×20Ω | `-1030A1` 3×20Ω | 限制冲击 |
| 主接触器 | `-61Q3/-61Q5` 200kW | `-61Q1/-62Q1` 132/110kW | 全压供电 |
| 电容 | `-1031C1/-1032C1` 15 000µF | `-1080C1` 15 000µF | 滤波/储能 |
| 放电电阻 | `-1031R1/R2` 200Ω | `-1050R1/R2` 200Ω | 停机泄放 |

- 预充接触器和主接触器不串联；预充只给电容充电，主接触器给驱动供电。
- 每套上刀辊独立母线；HQ1/HQ2 不共直流母线。
- STO 是 24V 信号，接驱动 `-STO_A/-STO_B`，不切 400V。

## H SV 变化与常见错误
| SV 变化 | 400V 侧改什么 | 必看页 | 关键器件/电缆 |
|---|---|---|---|
| 单刀→双刀 | 增加 HQ2：PE、LVS 54/55/56/62、RLS 2000、KNB 2300 | `=MPS 15/16`、`=LVS 54/55/56/62` | `-62Q1`、`-2300T1`、`-2030A1` |
| 45→60kW | 驱动 132→200kW；接触器 110→132kW；电缆 3×50→3×70 | `=LVS 58/61/62`、`=KNB 1300/2300` | 851247517、851256275 |
| 45/60→112kW | 630A 开关、无变压器、400A 熔断器、200kW 接触器、250kW 模块 | `=MPS 10`、`=LVS 51/61`、`=KNB 1300/1302` | 851209539、851222122、3RT5075 |
| 柜冷 水→空 | `=SCC` 改空调/风扇；400V 支路改 `-75F1` | `=SCC 251/255/260`、`=LVS 75` | 851206627、851014791 |
| EU→CN | 名称牌/认证/电缆标准；400V 主链功率不变时不改 | `=IDP`、BOM | 851013368/851013372 |
| 400V→380V | 电流 +5.3%；熔断器/接触器/电缆重新核算 | `=MPS 10`、`=LVS 51` | 可能升档；查变压器抽头 |
| 加真空 | 增加 `-56F1 25A`、`-1650T1` | `=LVS 56`、`=VAC` | 4G2.5 电缆 |
| 加废纸带 | 增加 `-56F2..F5`、`-1770T1` 等 | `=LVS 56` | 25/16A 熔断器 |

**常见错误**
| 现象 | 正确读法 | 页 |
|---|---|---|
| 把 `-61Q1` 当主接触器 | AISLING 它是 4kW 控制接触器；主接触器是 `-61Q3/-61Q5` | `61 / PDF 17` |
| 把 `-51F1` 当断路器 | 它是 400A 熔断器座/隔离开关，无过载保护 | `51 / PDF 15` |
| 认为所有 HQ 都有变压器 | AISLING 无；ARAMIS/ALARIC 有 110kVA | `=LVS 51` |
| 用 125A 反推 200kW 满载 | 125A 只保护电缆/平均电流；峰值靠电容 | `58 / PDF 24` |
| 把 GEN 8 当有最大长度 | 该格是占位文字，无数字 | `8 / PDF 8` |
| 把 4mm² 配 32A 当正常 | GEN 6 表 4mm² 上限 25A；`-51F5` 待确认 | `51 / PDF 15` |

```callout err 三个必须确认
1. AISLING `-51F5` 32A 配 4mm²，超过 GEN 6 表 25A 上限。
2. AISLING `-81F1/F2/F3` 页写 NH00，BOM 写 14×51，两种熔断器体系。
3. ARAMIS/ALARIC `-51T1` 页上有，BOM 20–23 无行；订货前补行。
```

> 新平台差异：新 HQ-M（ADARA/BELEN/ROCH）用 +13501 供电、+13531/+13541 功率柜，`=LSV` 只有 3 页；SQ-M 用 13515/13545 单 HQ。不要把本页 AISLING/ARAMIS 的 400V 页段直接套到新项目。
