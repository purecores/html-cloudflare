端子图回答“接在哪”，电缆图回答“从哪到哪”，线号回答“这根线叫什么”。三张表必须能互相对上。对不上，就先查柜号和页段。

## B 端子页字段
每页一排端子，表头固定。

| 字段 | 含义 | 示例 |
|---|---|---|
| Destination 1/2/3 | 目标器件/端子 | `==GEN=STE-305K1 14` |
| terminal number | 端子号 | `1` |
| connection | 连接/芯线 | `1` |
| terminal size | 端子尺寸 | `1,5 mm²` |
| terminal symbol | 端子符号 | 圆点/接地 |
| bridge | 短接片 | 空 / `1–2` |
| cable name | 电缆型号 | `25x1,5 mm² JZ-500 -503WC1` |
| page/path | 页/列 | `&WDA==GEN/503.1` |

例：X531 的 1 号端子。

```text
目标 1：==GEN=STE-305K1  14
端子号：1
目标 2：+13531-X511  1:a
页/列：&WDA==GEN/503.1
尺寸：1,5 mm²
```

端子号可展开到连接面：`-XPE:1:a;d`。`a` 是内线侧，`d` 是外线侧。

## D 电缆号与长度
| 类型 | 规则 | 例子 |
|---|---|---|
| 外部控制 | `WC` + 3 位 | `-WC461`、`-WC560`、`-WC571`、`-WC591`、`-WC666` |
| 外部动力 | `WP` + 5 位 | `-WP13001…13004`、`-WP13010…13018` |
| 数据 | `WD` + 3 位 | `-WD596`、`-1WD01…` |
| 内部通用 | `W` + 5 位 | `-W13170`、`-W13716` |
| 内部页+类型+去向 | 页号+W+类型+器件 | `-58WP1`、`-701WC3`、`-1090WCY1` |
| 带位置前缀 | `+柜号-W…` | `+13033-W13711`、`+13545-W13175` |

长度单位是米。外部常见 40/60/80/100 m。内部常见 2–12 m。

长度是设计长度，不是现场实测。电缆物料要在部件属性里填长度。

## E 线号、颜色、截面
线号格式：`<3 位页号>-<2 位序号>`。

| 线号 | 页 | 场景 |
|---|---|---|
| `010-01` | 10 | 主进线 |
| `301-01` | 301 | 安全回路 |
| `503-01` | 503 | 柜间 STO |
| `504-01` | 504 | 柜间信号 |
| `510-09` | 510 | DF 急停 |
| `518-01` | 518 | KQ AOC |
| `540-01` | 540 | AS 急停 |

| 颜色 | 用途 | 截面 |
|---|---|---|
| `OG` | 安全/控制信号 | 1.5 mm² |
| `BK` | 动力/0 V | 1.5–150 mm² |
| `BU` | 24 V+ | 2.5 / 6 mm² |
| `RD` | 230 V 火线 | 1.5 / 2.5 mm² |
| `GNYE` | PE | 2.5–120 mm² |
| `WH` | 信号/中性 | 1.5–16 mm² |

图纸印成 `1,5 mm² OG 510-09`。截面范围 0.75–240 mm²。

线号绑定画线页。同一根线在对端页会重复印号。`510-09` 同时出现在 PDF 58 和 61，这是正常的。

## F 端子附件、BOM 与布置图
| 附件 | 作用 | 何时需要 |
|---|---|---|
| 端子本体 | 导电/压线 | 每个端子 |
| 端板 | 相邻端子绝缘 | 每排两端/不同电位 |
| 终端固定件 | 防端子排滑动 | 每排两端 |
| 保护罩 | 防触电 | 400 V/230 V |
| 标记卡 | 端子号标识 | 每个端子 |
| 端子排标记卡 | 端子排名称 | 每排 |

隔离开关是组件：本体 + 保护罩 + 手柄 + 延长杆 + 接线鼻（单芯线 ≥25 mm²）。

导出端子排 BOM 时，排除 Wire harness assembly parts。

BOM 在 LAY 的“箱柜设备清单”页。字段与两个实例如下：

| 字段 | 风扇 | 端子排 |
|---|---|---|
| Position | 2 | 75 |
| DT | 251M1 | X531 |
| Part number | 851014791 | （空） |
| Type | PFB 7.000 | |
| designation | cooling fan 230VAC | |
| function text | | |
| Safety | | |
| Sheet | 251.1 | 503.1 |

```flow LR
实物位置 -> 布置图 -> BOM -> 电路页
```

例：柜内位置 2 → 布置图 `2 251.1 -251M1` → BOM 第 2 行 → 图页 251.1。

> 端子排 BOM 行的部件号常为空。端子、端板、标记卡要手工补。

## G 改图七步
| 层 | 改什么 | 检查 |
|---|---|---|
| 1 信号 | 矩阵 + PLCV + 405.x | 地址/端子/过程位 |
| 2 DEX | 选对端页、端子对、光耦/继电器 | 快/慢信号 |
| 3 端子 | CON 加行：端子号、目标、尺寸、页 | 端子排总数 |
| 4 电缆 | WRE 加行：起止、长度、型号、部件号 | 芯数/备用芯 |
| 5 线号 | WDA 加号：页号-序号、颜色、截面 | 不与同页冲突 |
| 6 BOM | LAY 加行：Position/DT/Part/Sheet | 附件/电缆长度 |
| 7 交叉检查 | CON、WRE、BOM、PLCV、设备树 | 五处一致 |

检查表：

1. 新信号是否真的跨机。
2. 对端是否有现成端子排。
3. 电缆芯数是否留备用。
4. 屏蔽线是否有 `SH` 端子。
5. 线号页号是否等于画线页。
6. BOM 是否补附件、组件、长度。
7. BOM 的 Sheet 是否指向新页。
8. 是否残留旧柜号/旧页名。

## H 常见错误与待确认
| 现象 | 原因 | 处理 |
|---|---|---|
| 端子号当过程位 | 端子顺序 ≠ 过程位 | 按 405.x 核对 |
| 长度写成 mm | 单位混淆 | 统一 m |
| 屏蔽没接地 | 屏蔽对未处理 | 接 `SH`/PE |
| 线号“重复” | 同一根线两端 | 查画线页 |
| 跨柜端子对不上 | 两端号相同、柜不同 | 量两端 |
| 旧柜号残留 | 模板复用未改 | 以 DEX 页为准 |
| 旧页名残留 | 模板复用未改 | 按端子找页 |
| 端子排无部件号 | 端子排由多物料组成 | 手工补附件 |

> ALARIC 的 `-WC592/-WC594` 是 `PAAR-TRONIC-CY 4×2×0.5`，端子 11 为 `SH`。这是屏蔽对，不能当普通 24 V 线。
