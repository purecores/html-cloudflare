改图改的是 EPLAN 源项目，不是 PDF。复制页只是开始；标签、引用、端子、电缆、报表和 BOM 必须一起改。

## A 数据模型与复制页

项目包含页；页包含设备；设备挂部件；端子属于设备；电缆连接设备。报表从设备数据生成，不要手画表格。

```tree
项目
  页 | &WDA==GEN=MPS+13501 HQ/10
    设备 | -10Q1 主开关
      部件 | 851209539 ×1
      端子 | -XPE:1
    电缆 | -WP13001
  报表 | 箱柜清单、端子总览、电缆总览
```

```flow LR
(EPLAN 源项目) -> 报表页: 生成
报表页 -> (导出 PDF): 导出
(EPLAN 源项目) -> ILC 接口: 读取
ILC 接口 -> (SAP BOM): 释放
```

| 对象 | 角色 | 谁产生 |
|---|---|---|
| EPLAN 源项目 | 唯一源数据 | 设计员 |
| 导出 PDF | 评审与现场快照 | 由源项目导出 |
| SAP BOM | 采购与发料清单 | 由 ILC 释放 |

> 不要手改 PDF。下次导出会覆盖手改内容，BOM 也不会同步。

### 打开与复制

菜单名以 P8 2025 实际界面为准；下面给出常用路径。

1. 打开参考项目，核对图号与版本。
2. 项目 → 复制，选择带项目数据。
3. 改项目名、图号、订单号、客户。
4. 打开页导航器，选中源页。
5. Ctrl+C、Ctrl+V，设目标页号与页名。
6. 保存后逐项核对下面五类对象。

页名 `&WDA==GEN=MPS+13501 HQ/10` 的读法：

| 段 | 示例 | 含义 |
|---|---|---|
| 文档类型 | &WDA | 电路图 |
| 高层功能 | ==GEN | 通用部分 |
| 功能组 | =MPS | 主电源 |
| 位置 | +13501 | 1 号柜 |
| 工厂/页 | HQ/10 | 工厂 HQ，第 10 页 |

| 对象 | 复制后必改 | 核对入口 |
|---|---|---|
| 页 | 页号、页名、结构 | 页导航器 |
| 设备 | 标签、前缀、唯一性 | 设备树 |
| 引用 | 触点、线圈、端子 | 逐条点开 |
| 端子/电缆 | 号、长度、线号 | &CON / &WRE |
| 报表 | 箱柜清单、BOM | &LAY / ILC |

> EPLAN 可能保留原标签；不要假设自动重编号。页号不是 PDF 页码；列号是 0–9。

## B 设备标签与交叉引用

标签格式为 `-<页号><字母><序号>`。前缀是主功能页，不是绘图页。

| 标签 | 拆法 | 说明 |
|---|---|---|
| -10Q1 | 10 + Q + 1 | 第 10 页主开关 |
| -301K1 | 301 + K + 1 | 第 301 页安全继电器 |
| -1300T1 | 1300 + T + 1 | 第 1300 页主传动 |
| -XPE | 功能命名 | 端子排不按页号 |
| -WC461 | 类型 + 流水 | 外部电缆不按页号 |
| -405A1-K202 | 405 + A1 + K202 | PLC 机架与卡号 |

改标签的顺序：

1. 打开设备导航器，选中设备。
2. 在属性中改完整设备标识 Full DT。
3. 确认前缀等于主功能页。
4. 更新连接与交叉引用。
5. 全图搜索旧标签和旧页号。
6. 在设备树与设备标签列表复核。

例：`-1920Y1` 画在 1930 页，前缀仍是 1920。

> 不要用文本替换批量改标签；会留下重复标签和空引用。交叉引用写法 `/301.1` 表示第 301 页第 1 列。

## C 端子与电缆

端子排和电缆都是设备；它们也有属性、部件和报表页。

| 对象 | 编辑入口 | 必查 |
|---|---|---|
| 端子排 | 项目数据 → 端子 → 端子排 | 端子号、短接片、附件 |
| 电缆 | 项目数据 → 电缆 → 电缆编辑 | 型号、芯数、长度、屏蔽 |
| 线号 | 连接编号（以实际菜单为准） | 页号-序号 |
| 报表页 | &CON / &WRE | 端子总览、电缆总览 |

端子附件不能漏：端子、端板、终端固定件、保护罩、标记卡、端子排标记卡。

电缆长度写在 `Subset / length`，单位用 m。长度进入 BOM 数量，不能只填件数。

线号 = 页号-序号，例如 `301-01`。复制页后按新页号重编线号。

> `&CON` 和 `&WRE` 是报表/图表页；改完源数据要重新生成。

## D 报表与 BOM

箱柜设备清单在 `&LAY`，按柜号分页。表头固定七列。

| 列 | 含义 | 检查 |
|---|---|---|
| DT designation | 设备标签 | 与电路页一致 |
| Position | 柜内位置号 | 与布置图一致 |
| Part number | 部件号 | 与 Parts 一致 |
| function text | 功能文本 | 可读、无旧名 |
| Sheet | 图页.列 | 能跳回电路页 |
| Type | 型号 | 与部件库一致 |
| Safety relevant | 安全相关 X | 安全件必须标 |

更新报表与 BOM：

1. 工具 → 报表 → 生成。
2. 选箱柜设备清单，更新全部页。
3. 核对行数、部件号、数量、位置。
4. 新增器件必须重生成报表。
5. 导出 BOM，核对 3401.xlsx 列。
6. SAP 选项卡 → ILC → Create BOM。

`3401.xlsx` 是 SAP 导出，不是源文件。重点核对组件号、数量、单位和行号。

> 图纸有 ≠ BOM 有。AZARIA 的 SPD 传感器和 ANSEL 的 CMC 传感器都曾漏 BOM。

## E PDF 导出与版本

1. 文件 → 导出 → PDF。
2. 选全部页或页范围。
3. 勾选书签与结构。
4. 输出名带版本号。
5. 核对页数、书签、图框。
6. 归档旧版 PDF 与项目。

导出菜单以实际版本为准。

| 核对项 | 标准 |
|---|---|
| 页数 | 图框 Number of pages 等于 PDF 页数 |
| 书签 | 四类书签齐全 |
| 图框 | 项目、图号、版本、修改人、日期正确 |
| 页脚 | EPLAN 版本与 CAD 号正确 |
| 旧版 | 旧 PDF 与旧项目已归档 |

版本示例：AISLING 001.000.006，238 页。ARAMIS 001.000.005，373 页；ALARIC 001.000.005，346 页。

> PDF 第 9 页可能是 EPLAN 第 10 页；用书签跳。

## F 操作检查表

复制页后 10 项：

| # | 检查项 |
|---|---|
| 1 | 页号、页名、结构正确 |
| 2 | 图框字段与项目一致 |
| 3 | 设备标签唯一、前缀正确 |
| 4 | 交叉引用指向新页 |
| 5 | 端子排与端子已复制 |
| 6 | 电缆号、长度、线号已改 |
| 7 | PLCV 与 IO 地址已同步 |
| 8 | 布置图位置号与 BOM 已改 |
| 9 | 旧项目、旧柜号已搜清 |
| 10 | 报表已重生成，PDF 已重导 |

改标签后 8 项：

| # | 检查项 |
|---|---|
| 1 | Full DT 已改，不只改显示 |
| 2 | 前缀等于主功能页 |
| 3 | 无重名、无空标签 |
| 4 | 设备树位置正确 |
| 5 | 设备标签列表能查到 |
| 6 | 全图搜不到旧标签 |
| 7 | 交叉引用全部指向新标签 |
| 8 | 箱柜清单行已更新 |

改端子/电缆后 8 项：

| # | 检查项 |
|---|---|
| 1 | 端子排属于正确柜号 |
| 2 | 端子号连续、不重复 |
| 3 | 端板、终端固定、保护罩、标记卡齐全 |
| 4 | 短接片与桥接正确 |
| 5 | 电缆号、型号、芯数正确 |
| 6 | 长度单位为 m，数值正确 |
| 7 | 屏蔽与 PE 连接正确 |
| 8 | &CON/&WRE 与线号已更新 |

导出前 6 项：

| # | 检查项 |
|---|---|
| 1 | 报表全部更新 |
| 2 | 无空引用、无问号 |
| 3 | BOM 无缺料号 |
| 4 | 页数、书签、图框一致 |
| 5 | 版本、修改人、日期已改 |
| 6 | 旧版已归档，PDF 与源项目一致 |

## G 常见错误

| 错误 | 现象 | 正确做法 |
|---|---|---|
| 只改电路页 | 端子、电缆缺页 | 同步 CON、WRE、PLCV |
| 标签前缀错 | 引用和 BOM 对不上 | 前缀等于主功能页 |
| 引用指向旧项目 | 跳错页、查错线 | 更新引用并逐条点开 |
| 旧柜号残留 | 现场走错柜 | 搜 13505、13545、13515 |
| 端子附件漏 | BOM 缺端板、标记卡 | 补齐端子附件 |
| 电缆长度单位错 | BOM 数量错 | 用 m，核对 Subset/length |
| 报表未更新 | SAP 缺件或错件 | 重新生成箱柜清单 |
| 手改 PDF | 下次导出丢失 | 只改 EPLAN 源项目 |

> 触及安全链、主传动、柜体或标准，停手找师傅。
