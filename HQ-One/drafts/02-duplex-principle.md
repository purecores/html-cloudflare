先纠正三个关键点。第一，**一套横切单元的上下刀杆是一副剪刀的两个半边**，下刀杆机械联动，不单独驱动。第二，**双电机都驱动上刀辊**，不是一台电机驱动上刀、一台驱动下刀。第三，**双刀是两套完整横切机组，分到上下两条纸路，各切各的切长**；不是一根辊上两片刀，也不是两套刀交替切同一刀线。

## A 三个层级的“刀”
| 层级 | 指什么 | 数量关系 |
|---|---|---|
| 刀杆/刀片 | 上刀杆 + 下刀杆反向旋转，各装一片长刀片 | 一副剪刀的两个半边 |
| 横切单元 | 一对上下刀杆 + 上刀辊驱动 + 进出纸 + 机架 | 一套 = 一个独立切长 |
| 双刀 | 两套完整横切机组，上下两层纸路 | 两副剪刀，各切各的 |

> 生产稳态下，成品板只被一副剪刀切一刀；换单时被切两刀的是本来就要扔掉的过渡废片。

## B 一套横切单元的真实结构
| 部件 | 数量/驱动 | 说明 |
|---|---|---|
| 上刀杆/上刀辊 | 1 根，2 台电机（OS/DS） | 两台电机同轴驱动上刀辊；两端分置，抑制扭转 |
| 下刀杆 | 1 根 | 通过机械联动与上刀杆反向旋转，不单独配电机 |
| 刀片 | 上下各一片长刀片 | 螺旋角安装，从幅宽一端扫到另一端 |
| 编码器 | 上刀辊/测量辊 | 切长、相位、速度反馈 |
| 进/出纸 | 进料辊、出料辊/站 | 建立板速与张力 |
| 制动/储能 | 直流母线电容组 | 每个横切单元一套 |

```flow LR
(上刀辊 2×电机) -> (上刀杆)
(上刀杆) -> (下刀杆): 机械联动
(上刀杆) & (下刀杆) -> (剪刀啮合)
(剪刀啮合) -> (切断纸板)
```

> 所以“2×45/2×60/2×112kW”说的是**一个上刀辊两端的电机**，不是两台横切机，也不是上下刀各一台。双刀整机有 2 套上刀辊，共 4 台主电机。

## C 单刀运动：切一刀的全过程
单刀单元每转一圈切一刀。关键是：**刀尖在接触纸板时必须与纸板同速**，切完再加速到顶点、再减速回到下一刀的同步速度；它不是每刀从零启动、也不是切完就停；电机在下一次剪切前保持旋转。

```timeline
0 ms | 剪切点 0° | 刀尖线速 = 板速，进入剪切窗
17.8 ms | 切出 | 刀尖离开纸板，开始加速
83.3 ms | 180° 顶点 | 刀尖达到峰值速度
149 ms | 减速中 | 回到接近板速
166.7 ms | 360° 下一刀 | 再次与板速同步
```

| 阶段 | 发生什么 | 控制要点 |
|---|---|---|
| 剪切窗 | 上下刃口啮合，刀尖线速 = 板速 | 相位/速度同步，切窗角度由板厚决定；D210/7mm 板约 42°、77mm 弧长 |
| 加速段 | 刀尖离开纸板后加速 | 按凸轮/速度曲线限幅，避免过流 |
| 顶点 | 180° 附近速度最高 | 惯量决定峰值功率与温升 |
| 减速段 | 回到同步速度 | 能量回母线电容，下一刀再用 |
| 下一刀 | 再次进入剪切窗 | 切长/订单变化时重算周期 |

> 180 m/min、500 mm 时：切长/板速 = 166.7 ms 一刀；250 m/min 时 120 ms；400 m/min 时 75 ms。车速越高、切长越短，周期越短，加减速越猛。剪切窗按 D210、7mm 板约 42°、77mm 弧长、180 m/min 时约 25.7 ms；切窗必须短于切长。

## D 单刀公式与算例
设刀辊半径 $R$、板速 $v$、切长 $L$、转动惯量 $J$、板厚 $h$。

$$
T=\frac{L}{v},\quad f=\frac{1}{T}=\frac{v}{L}
$$

$$
\omega_c=\frac{v}{R},\quad \bar{\omega}=\frac{2\pi}{T},\quad \omega_e=2\bar{\omega}-\omega_c
$$

$$
\alpha=\frac{2\pi|\bar{\omega}-\omega_c|}{T},\quad T_{peak}=J\alpha,\quad P_{peak}=T_{peak}\omega_c
$$

$$
\Delta E=\frac{1}{2}J(\omega_e^2-\omega_c^2),\quad \theta_w=2\arccos\left(1-\frac{h}{R}\right),\quad t_w=\frac{\theta_w}{\omega_c}
$$

| 量 | 含义 | 180 m/min、500 mm、D210、J0.9 |
|---|---|---|
| R | 刀辊半径 | 0.105 m |
| T | 每刀周期 | 166.7 ms |
| f | 切次频率 | 6.0 次/秒 |
| ω_c | 剪切点角速度 | 28.6 rad/s |
| ω_avg | 周期平均角速度 | 37.7 rad/s |
| ω_e | 顶点角速度 | 46.8 rad/s |
| α | 峰值角加速度 | 343 rad/s² |
| T_peak | 峰值力矩 | 约 311 N·m |
| P_peak | 剪切点峰值功率 | 约 8.9 kW |
| ΔE | 一个周期动能摆动 | 约 619 J |

| 工况（D210、J0.9、500 mm） | 周期 | 切次 | ω_c | α | P_peak | ΔE |
|---|---:|---:|---:|---:|---:|---:|
| 180 m/min | 166.7 ms | 6.0/s | 28.6 | 344 | 8.8 kW | 619 J |
| 250 m/min | 120 ms | 8.33/s | 39.7 | 664 | 23.7 kW | 1195 J |
| 400 m/min | 75 ms | 13.3/s | 63.5 | 1699 | 97.1 kW | 3059 J |
| 450 m/min | 66.7 ms | 15/s | 71.4 | 2151 | 138.3 kW | 3871 J |

> 表内按“每刀半圈加速、半圈制动”的速度曲线估算；J=0.9 kg·m² 是参考文档的工程推测，实际以机械图/铭牌为准。`P_peak = T_peak·ω_c` 是剪切点功率；若用 $J\bar{\omega}\alpha$ 估算会略高，两者都只能作量级判断。

## E 双刀：两套机组、两条纸路
```flow LR
(双面机DF) -> (旋转剪KQ)
(旋转剪KQ) -> (纵切压线SR)
(纵切压线SR) -> (分纸拨叉)
(分纸拨叉) -> (上层纸路HQ1)
(分纸拨叉) -> (下层纸路HQ2)
(上层纸路HQ1) -> (上层堆码AS1)
(下层纸路HQ2) -> (下层堆码AS2)
```

| 维度 | 单刀 | 双刀 |
|---|---|---|
| 横切单元 | 1 套 | 2 套（HQ1/HQ2） |
| 纸路 | 1 条 | 上下 2 条 |
| 同一时刻切长 | 整幅只能一种 | 两条纸路可各一种 |
| 每套上刀辊电机 | 1 或 2 台 | 每套 1 或 2 台，共 2 或 4 台 |
| 下刀杆 | 机械联动 | 每套机械联动 |
| 成品板 | 切一刀 | 仍只切一刀 |
| 换单废片 | 可能两刀 | 可能两刀 |

> 双刀的核心收益是“解除整幅同一时刻只能有一种切长的约束”，不是把单把刀的周期翻倍。两套机组各按自己的 $L_i$ 和 $v$ 运行；如果两条纸路切长相同，它们可以同步，但不是必须相位差半圈。

## F 控制逻辑：排单、加减速与匀速切换
```flow LR
(订单/排单) -> 切长L与车速v
切长L与车速v -> 周期T=L/v
周期T=L/v -> 凸轮/速度曲线
凸轮/速度曲线 -> 剪切窗同步ω_c=v/R
剪切窗同步ω_c=v/R -> 加速/减速
加速/减速 -> 下一刀/换单
```

| 控制环节 | 做什么 | 目的 |
|---|---|---|
| 订单/排单 | 读取切长、张数、材质、换单点 | 决定每套机组的 L 与目标切次 |
| 速度前馈 | 用板速 v 算 ω_c=v/R | 在剪切窗内锁住板速 |
| 凸轮/曲线 | 生成加速—顶点—减速—同步曲线 | 保持旋转，不做每刀零速启停 |
| 同步窗口 | 刀尖线速与板速一致 | 切口垂直、不拉毛 |
| 限幅 | 限制 α、电流、母线电压 | 防止过流/过压 |
| 预充/电容 | 先预充，再使能；电容吸收/释放 | 减少启动冲击电流 |
| 换单 | 重算 L/T/相位，必要时降速 | 保证新订单首张切长 |
| 安全 | STO/急停封锁脉冲 | 人身安全优先 |

> “匀速切换”指在剪切窗内保持与板速同步的匀速段；不是整圈都匀速。不同车速/切长时，控制器自动切换加速、减速和同步段；靠预充和母线电容把启动冲击电流压下去，而不是每刀重新启动电机。

## G 电容组分析与公式
每个横切单元一套直流母线电容组；双刀两套独立。电容的作用是：预充限制合闸冲击；加速时释放能量；减速时吸收动能；把进线电流“削峰填谷”。

$$
E_{avail}=\frac{1}{2}C(U_{max}^2-U_{nom}^2)
$$

$$
\Delta E=\frac{1}{2}J(\omega_e^2-\omega_c^2)
$$

$$
C_{min}=\frac{2\Delta E}{U_{max}^2-U_{nom}^2},\quad J_{max}=\frac{2E_{avail}}{\omega_e^2-\omega_c^2}
$$

$$
\Delta U=\sqrt{U_{nom}^2+\frac{2\Delta E}{C}}-U_{nom}
$$

| 量 | 参考值/公式 | 说明 |
|---|---|---|
| C_bus | 15 000 µF/单元 | 参考双刀图纸；实际以 BOM 为准 |
| U_nom | 540–565 V | 400V 整流 |
| U_max | 620/700/775 V | 过压阈值假设，按驱动器手册 |
| E_avail | 696/1281/2111 J | 对应 540→620/565→700/565→775 |
| 预充 | 3×20Ω 串联，τ=R C | 60Ω×15mF=0.9s；5τ≈4.5s |
| 放电 | 2×200Ω 并联，τ=R C | 100Ω×15mF=1.5s；5τ≈7.5s |
| 合闸冲击 | I≈U/R_pre | 565/60≈9.4A，预充限制 |

| 工况（J0.9、500 mm、C15mF） | ΔE | 565→700V 可用 | 结论 |
|---|---:|---:|---|
| 180 m/min | 620 J | 1281 J | 够，ΔU≈69V |
| 250 m/min | 1195 J | 1281 J | 接近上限，ΔU≈119V |
| 400 m/min | 3059 J | 1281 J | 不够，需 C≈40mF 或降 J |
| 450 m/min | 3871 J | 1281 J | 不够，需 C≈50mF 或降 J |

> 这说明 15 000 µF 不是所有工况万能：短切长 + 高线速时，必须核对惯量、电容和母线过压。实际 J 若降到 0.4–0.5，400–450 m/min/500 mm 才可能落在 15–20mF + 700–775V 的窗口内。

```callout warn 放电电阻不是制动电阻
- 制动每个剪切循环都发生，能量进母线电容（刀辊）或制动电阻（辅助轴）。
- 放电只在停机后发生一次，把电容泄放到安全电压。
- 把放电电阻当制动电阻用，几秒就会烧。
```

## H 车速、幅宽、切长如何影响主驱动
| 变量 | 变化 | 对主驱动的影响 |
|---|---|---|
| 车速 v | 升高 | ω_c=v/R 升高，切次增加；功率随 v 与 α 上升 |
| 切长 L | 减小 | T=L/v 减小，α、峰值转矩、峰值功率上升 |
| 幅宽 W | 增大 | J∝L 线性增加；临界转速∝1/L² 下降；需 CFRP/高刚度，不能只加粗 |
| 刀辊直径 D | 增大 | J∝D³ 恶化，ω_c=v/R 下降；不利于短切长 |
| 刀辊材料 | 钢→CFK | 比模量提高 3–5 倍，J 降低，短切长能力提高 |
| 螺旋角 θ | 增大 | 轴向扫程 W·tanθ 增大，同步角/扫切时间变化；宽幅建议约 1.7°、不超过 2° |
| 单/双刀 | 单→双 | 两套独立切长/纸路；总装机功率约翻倍，不互为备用 |
| 电机并联 | 45/60kW 两台并联一台模块 | 单模块带两台电机，需均流/同轴刚性 |
| 单驱 | 90/112kW 每台电机一台模块 | 两台模块同步，避免刀辊扭转 |

> 选型先算“最苛刻订单”的 T、α、P、ΔE，再选电机/模块/电容；不要用铭牌功率倒推切长能力。

## I 常见误解
| 误解 | 事实 |
|---|---|
| 双刀 = 一根辊上两片刀 | 双刀是两套完整横切机组；一辊两片刀是另一种路线 |
| 双刀 = 两台半幅刀机 | 每套刀辊都是全幅能力，纸路分半但刀辊不缩水 |
| 成品板被切两刀 | 成品只切一刀；换单废片才可能两刀 |
| 2×60kW 是刀辊参数 | 是每套上刀辊两端的电机功率，不是刀辊直径/惯量 |
| 双刀两套刀交替切同一刀线 | 两套机组分上下纸路，各切各的切长，不要求相位差半圈 |
| 下刀杆也有电机 | 下刀杆机械联动；双电机都驱动上刀辊 |
| 电容越大越好 | 电容按 ΔE、电压窗口、预充/放电时间选；过大增加体积/冲击 |

## J 现场核对清单
| 核对项 | 看哪里 | 注意 |
|---|---|---|
| 上刀辊电机数量/功率 | `=KNB` + SV | 2× 是上刀辊两端，不是两台机 |
| 下刀杆驱动 | 机械图/`=KNB` | 机械联动，不应有独立电机 |
| 刀辊直径/惯量 | 机械图/铭牌/盘车 | 公式里的 R、J 不能猜 |
| 驱动型号 | `=KNB`/`=SDC` | 新旧平台不同 |
| 电容组 | `=RLS`/`=KNB` 母线页 | 每单元一套；双刀两套 |
| 预充/放电 | 母线页 | 预充限制冲击；放电只停机用 |
| 切长/车速 | SV + 排单 | 用最苛刻订单核算 |
