## B 案例 D：加门锁

```flow
(ARAMIS/AISLING 无门锁) -> 加 318/325 柜门锁
加 318/325 柜门锁 -> 加 360–363 安全门锁
加 360–363 安全门锁 -> 加 Q109/DI105
加 Q109/DI105 -> BOM 318K1/325K1
```

| 维度 | 页级变化与证据 |
|---|---|
| SV 变化 | 样本中 ARAMIS、AISLING 全册无 Q109、318K1、325K1。ARLEN、ALARIC 有门锁页。 |
| 图纸页变化 | ARLEN：318/52、325/54 为柜门锁；360–363/55–58 为安全门。ALARIC：360–363/52–55。 |
| 器件/端子/电缆 | 318K1/325K1 为 Finder 3WE，851085983。318S1/325S1 为 Siemens 851060749。门开关 360S1 为 GP-71PC 851180700。S6 为 851220262。Q109.0–Q109.11 去门锁和灯。318/325 反馈到 I105.10/I105.11。电缆 318WS1 851060117、318WB1 851061642、W13130 851033615。 |
| BOM/ILC | 箱柜清单 PDF 222 有 318K1 位置 86。PDF 229 有 325K1 位置 307。PDF 236 有 318K1 位置 70。ILC 按 13525/13545 位置挂 Item。 |
| 风险点 | DO11/DO12 不是两把锁。ARLEN 的 DO11 是 Q109.11，去 363S6 的“可开门”灯。DO12 是 Q109.12，空置。门锁输出是标准 DO，不是安全输出。 |
| 评审门 | 安全评审。查门锁逻辑、S6 复位、OSSD 双通道、BOM 行。 |

```callout warn 不要短接 Q109
门安全靠 360S1 的 OSSD1/2，不靠门锁输出。短接 Q109 不能旁路门安全。
```

## D 案例 F：加安全中心

| 维度 | ALARIC（EU，有安全中心） | ARAMIS/AISLING（CN，无安全中心） |
|---|---|---|
| SV 变化 | EU 配置含安全中心 | CN 样本没有 |
| 图纸页变化 | 560/92、565/93。K14 14/165。K20 20/167。K21 21/168。405/64。375/58。 | 405/64 只有 K10–K13、K20。无 560/565。 |
| 器件/端子/电缆 | XSAFCC1/2。WC580/581 为 JZ-500 12G1.5 60 m，851150915。K14/K15 为 EL1904 851167837。K20/K21 为 EL2904 851167833。320K1 触点 13/14、23/24 回安全中心。 | 无 K14/K15/K21。安全输出只有 K20。 |
| BOM/ILC | K14、K15、K21 是新增模块。急停和 Stop-Safe 各用一对输入。ILC 同步加这三块。 | BOM 没有这三块。 |
| 风险点 | 任务写 DI5/DO2。ALARIC 安全中心页没有这两个名字。实际落点是 K14 的 I204.0–I204.3，和 K20/K21 的 Q200.0、Q200.2、Q201.0、Q201.2。K20 DO2 在 EU 下空置。 | 只加 EL2904 不够。CN 没有安全中心页和 12 芯电缆。 |
| 评审门 | 安全评审 + SISTEMA/安全评估 + 急停/Stop-Safe 定义确认。 | 安全评审 + 配置确认。 |

```callout info 急停与 Stop-Safe 是两对信号
XSAFCC1 走急停，进 I204.0/I204.1。XSAFCC2 走 Stop-Safe，进 I204.2/I204.3。只改 EPLAN 不改安全程序，安全中心不生效。
```

## E 案例 G：加堆码机接口

| 维度 | 页级变化与证据 |
|---|---|
| SV 变化 | Stacker/AS 接口 = Yes。AISLING 只有 AS 急停，没有堆码机动力和握手。 |
| 图纸页变化 | ARAMIS：LVS 56/23 加 56F1–56F5；WEV 1770/135、1780/136、2770/170、2780/171；DEX 540/82、543/83、551/84–552/85。ARLEN：DEX 543/87、544/88、545/89。 |
| 器件/端子/电缆 | 56F1 25 A 真空。56F2/56F4 25 A 上/下堆码废纸带 1。56F3/56F5 16 A 废纸带 2。56WP1–56WP5 为 JZ-500 4G2.5 9 m，851159689。1770T1/1780T1 为 i550，851213950。ARAMIS DEX 543/83 用 543K1/K3/K4 光耦，851153522；DEX 540/82 用 XESAS 电缆 WC591，JZ-500 25G1.5 60 m，851150914；DEX 551/84–552/85 用 CCC 电缆 WC666，JZ-500 25G1.5 80 m，851150914。ARLEN DEX 543/87 用 543K1–K8 光耦，543K10 为 AOC Running 继电器 851086002（换单）；AS 电缆 WC550 为 JZ-603 18G1.5 60 m，170333。 |
| BOM/ILC | ARAMIS BOM 220 有 56F1–56F5。224 有 1770T1/1780T1。ARLEN BOM 228–230 有 543K1–543K10。AISLING 没有这些行。ILC 按 13505/13515 挂 Item。 |
| 风险点 | AS 接口不是一根线。动力、急停、握手、换单分开画。Good Cut 只在 ARLEN 的 DEX 543 出现。ARAMIS 用剪切脉冲去 AS。80 ms 脉冲和光耦不能省。 |


| 维度 | ALARIC EU / 45 kW | AISLING CN / 112 kW |
|---|---|---|
| SV 变化 | Electrical standard：EU → CN。功率也从 45 kW 变到 112 kW。两个变量同时变。 | 同左 |
| 图纸页变化 | MPS 10/10。LVS 51/18。LVS 61/24。 | MPS 10/9。LVS 51/15。LVS 61/17。 |
| 器件/端子/电缆 | 主开关 400 A，170431750。-51T1 为 851229303。二次 95 mm²。58F1/F3 125 A。主接触器 3RT5056-6AP36，266518190。 | 主开关 630 A，851209539。无主变压器。51F1/F2 400 A NH2。2×120 mm²。主接触器 3RT5075-6AP36，266518192。 |
| BOM/ILC | 3401 BOM 名称牌 EU 851013368（CE）。BOM 208 写 851256275/3RT5065，页 24 写 3RT5056。PDF 与 BOM 不一致，待确认。ILC 按订单挂名称牌和变压器。 | 3401 BOM 名称牌 CN 851013372（China/non-EU）。认证文件不在 EPLAN，待查。 |
| 风险点 | 主开关和接触器差异同时受功率影响。不能全归因于 EU/CN。 | 380 V 项目 AZARIA 与 400 V 项目 ANWEN 的 MPS 页都写 400 V/50 Hz。两页接触器都写 200 kW 266518192。BOM 报告却写 ANWEN 132 kW 851264439。PDF 与 BOM 冲突，待确认。 |
| 评审门 | 电气标准评审 + 主回路复算 + 名称牌/认证确认。 | 电气标准评审 + 电压/电流复算 + BOM 核对。 |

380/400 V 选择在 201T1 抽头表：380 V 用 2+5，400 V 用 2+4（ACV 201/27）。线色表 GEN 6/6 两项目相同：GNYE、BU/WHBU、RD/WHRD、BK、OG。EU/CN 不改线色。

```callout err 两个冲突先停下
ALARIC 主接触器：页 24 写 3RT5056，BOM 208 写 3RT5065。ANWEN 主接触器：页 17 写 200 kW 266518192，BOM 写 132 kW 851264439。释放前必须确认。
```

## G 共同模式、风险与评审门

```flow LR
(SV 变化) -> 功能组页
功能组页 -> 端子/电缆
端子/电缆 -> 柜号/布局
柜号/布局 -> BOM/ILC
BOM/ILC -> 评审门
```

| 案例 | 跨文档块 | 第一页 | 最后核对 |
|---|---|---|---|
| D 门锁 | STE + CON + LAY | 318/325 | 318K1/325K1 行 |
| E 真空 | WDA + LVS + PLCV + LAY | 801/675 | 泵、阀、电缆行 |
| F 安全中心 | DEX + PLCV + STE | 560/565 | K14/K21 行 |
| G 堆码机 | LVS + WEV + DEX + CON | 56F | 光耦、电缆行 |
| H EU/CN | MPS + LVS + GEN + BOM | 10/51 | 名称牌、变压器、接触器 |

页数接近不代表同模板。先看功能组、P 号、柜号段，再看页数。

| 风险 | 证据 | 处理 |
|---|---|---|
| 只复制 WDA 页 | 五个案例都跨文档块 | 同步 CON、WRE、LAY、BOM |
| BOM 缺口 | ANSEL 801Q1/801M1/1696Y1 不在箱柜清单 159–164 | 补行后再释放 |
| PDF 与 BOM 冲突 | ALARIC 3RT5056 对 851256275；ANWEN 200 kW 对 851264439 | 停下确认 |
| 安全输出当普通 DO | Q109 门锁、Q200/Q201 安全输出 | 安全评审 |
| 页号不变但 PDF 页序后移 | 新增页插在中间 | 用功能组定位，不按固定页号 |

| 门 | 谁 | 检查项 | 不通过 |
|---|---|---|---|
| 自检 | 改图人 | SV 逐项、页 diff、端子、电缆、BOM、安全 | 回到改页 |
| 互检 | 另一电气工程师 | 与参考项目逐页对比、页号、交叉引用 | 回到改页 |
| 安全评审 | 师傅或安全负责人 | 门锁、安全中心、STO、急停、安全 BOM | 停止释放 |
| 释放前 | 项目或电气主管 | EPLAN、PDF、BOM/ILC 一致 | 不释放 |
