## F 同一机型为什么差这么多
| 观察 | 解释 | 处理 |
|---|---|---|
| 山东与越南同为 SQ-M+，E/I 直接子行 476 vs 310 | 幅宽、选配、特殊变体、图纸版本都不同；具体差异要逐分支对比 | 按 E_13501/11/31/41 分支逐项比 |
| 阿联酋 E/I 直接子行 763，全后代 2031 | 双刀两套柜、两套驱动、两套 IO | 先看单/双刀，再看选配 |
| 山东比越南多 166 行直接子行（全后代多 409） | 山东 E_13511 128 vs 越南 41；E_13531 135 vs 49 | 查端子/电缆/选配/版本，待确认 |
| 三项目 BOM 总行都超过 1600 | 机械长尾多，不能只看总行 | 只看 E/I 分支与关键件 |
| 图纸页数 336/233/234 | 双刀多一套 HQ2，单刀页数接近 | 页数只用于找相似 |

> 结论：同机型不是同一份 BOM。先按“单/双刀→柜号→主传动→选配→标准”五层筛选，再逐分支核对。

## G 如果再来一单
```flow LR
(新订单) -> 读SV
读SV -> 定单/双刀
定单/双刀 -> 定柜号组
定柜号组 -> 找同柜号历史项目
找同柜号历史项目 -> 比主传动/刀梁
比主传动/刀梁 -> 比选配/标准
比选配/标准 -> 核图纸/BOM
核图纸/BOM -> ILC释放
```

| 步骤 | 动作 | 输出 |
|---|---|---|
| 1 | 读 SV，确认机型/框架/幅宽 | 配置画像 |
| 2 | 定单/双刀，选柜号组 | 旧平台 13501/13505；新 SQ-M 13515；新 HQ-M 13501 |
| 3 | 找同柜号、同幅宽、同主传动的历史项目 | 1–2 个参照 |
| 4 | 比选配与特殊变体 | 差异清单 |
| 5 | 核图纸功能组与 BOM 分支 | 电气差异清单 |
| 6 | ILC 释放并复核 | SAP BOM |
