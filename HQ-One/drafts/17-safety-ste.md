安全回路不是“一个急停按钮加一个接触器”。HQ 的链是：现场双通道设备 → 安全输入 → 安全程序 → 安全输出 → Dold 继电器 → 驱动 STO。先记三层，再看每层的端子和电缆。

## A 三层架构：先分清谁负责什么
```flow TB
[现场急停/门/LOTO/安全中心] -> [EL1918/EL1904 双通道输入]
[EL1918/EL1904 双通道输入] -> [TwinCAT Safety 安全程序]
[TwinCAT Safety 安全程序] -> [EL2904 安全输出]
[EL2904 安全输出] -> [Dold 301/305/327 或 320]
[Dold 301/305/327 或 320] -> [PM240-2 STO_A/B, i950 SIA/SIB]
[EL2904 安全输出] --> [Stop-Safe to DF/安全中心]
```
| 层 | 器件 | 作用 | 图纸 |
|---|---|---|---|
| 输入 | EL1918 8DI、EL1904 4DI | 采集双通道急停、门、LOTO、限位 | PLCV 10–13 |
| 逻辑 | C6015 + TwinCAT Safety | 安全功能、复位、差异监控 | 程序不在 EPLAN，【推断】 |
| 输出 | EL2904 4DO，0.5A | 输出 24V 安全信号 | PLCV 20/21 |
| 机电转换 | Dold UG 6929.60/100 | 双线圈、5 路常开触点 | STE 301/320 |
| 执行 | PM240-2、i950 | 封锁脉冲，实现 STO | STE 335/305/310 |

> 同一功能在不同模板标签不同：SQ 用 `301K1/305K1/327K1`，HQ 用 `320K1/330K1/366K1`。EU 的 ALARIC 只保留 `320K1`，STO 改由 `EL2904 K21` 直驱。不要跨项目抄标签。

## B 急停链：一个双通道环
```flow LR
[DF 急停] -> [XESDF 18 芯]
[XESDF 18 芯] -> [327K1/366K1 门触点]
[327K1/366K1 门触点] -> [380S1 5NC]
[380S1 5NC] -> [EL1904 K11 I201.2/3]
[380S1 5NC] -> [XESSR/XESAS]
[XESSR/XESAS] -> [SR/AS 急停]
[SR/AS 急停] -> [XESHQ 返回 DF]
```
| 端子 | 方向 | 电缆 | 规格 |
|---|---|---|---|
| `-XESDF` | HQ ↔ DF | `-WC461` | JZ-500 18G1.5 |
| `-XESHQ` | 主电箱侧 | 同上 | 同上 |
| `-XESSR` | HQ ↔ SR | `-WC571` | JZ-500 18G1.5 |
| `-XESAS` | HQ ↔ AS | `-WC591` | JZ-500 18G1.5 |
| `-XSAFCC1/2` | HQ ↔ 安全中心 | `-WC580/581` | JZ-500 12G1.5，60 m |
| `-X715` | 操作箱 | `-380WCS1/-W13170` | H05VV5-F 34G1.5 |

- `-380S1` 是 3SU1、5NC：21/22、31/32 进 EL1904；41/42、51/52 进 XESDF 环；另有一路进 I203.2 作监控。
- 门继电器 `-327K1/-366K1` 的线圈由门限位链 `-LS-DR` 供电，不经过 PLC。门开 → 继电器失电 → 13/14、23/24 断开 → XESDF 环断。
- ALARIC 用 `380S1` 5NC 加 `380S4/S5/S6` 2NC 串联，双通道进 `K15 I205.0/1`；安全中心急停进 `K14 I204.0/1`。

> 急停环是双通道 ES1/ES2。短接任何一段、只接一路，都会让安全等级失效。复位前必须确认所有急停释放、门关闭、LOTO 闭合、安全中心正常。

## C 门与 LOTO：3 扇还是 5 扇
| 项目 | 门位置 | 安全开关 | 门锁/请求 | 门继电器 |
|---|---|---:|---|---|
| AISLING SQ-M+ | 3 | 321S1/S2、322S1/S2、323S1 | 无 | 327K1 |
| AUDRIC SQ-N | 3 | 321S1/S2、322S1/S2、323S1 | 无 | 327K1 |
| ARAMIS HQ-M | 3 | 360S1/S2、362S1/S2、363S1 | 无 | 366K1 |
| ALARIC HQ-M | 5 | 360S1、361S1、362S1、363S1、364S1 | 360–363 各 1 个 S6 | 无 |

```state TB
[*] -> 关门锁定
关门锁定 -> 请求开门: 按 S6
请求开门 -> 已解锁: Q109.x 得电
已解锁 -> 门开: OSSD 断开
门开 -> 关门锁定: 关门 + 复位
```
- CN 门开关是普通 3NC（851195333），电缆 JZ-500 7G0.75 或 JZ-602 7G1.5。
- EU 门开关是锁定型 GP-71PC（851180700），有 OSSD1/2、AUX、Lock control；S6 是请求/确认按钮（851220262）。
- KQ-M 的安全区是 321–326、371/372：ALARIC/ANDREAS 有 3 个 stop-safe（321–323），ROCH/SAMANTHA 有 6 个（321–326）。KQ 是旋转剪切子项目，安全链与 HQ 分开，不能套用 HQ 的门表。
- `Q109.0–Q109.11` 是标准 DO，只控制门锁和灯；安全状态来自 S1 的 OSSD。**短接 Q109.x 不能旁路门安全功能。** 别的模板可能用 `DO11/DO12` 做门锁，位号按项目，不要记死。
- LOTO 是 `I203.0/1` 双通道，走安全 PLC，没有硬布线触点串在 301K1 线圈里。现场 LOTO 开关只到 X715:9/10。

## D STO 与安全输出：停什么、怎么停
| 模块 | 位 | 端子 | 地址 | CN | EU |
|---|---|---|---|---|---|
| K20 | DO0 | 1/2 | `Q200.0` | Stop-Safe to DF | Stop-Safe to DF |
| K20 | DO1 | 5/6 | `Q200.1` | 备用 | 备用 |
| K20 | DO2 | 3/4 | `Q200.2` | STO → 305K1/330K1 | 备用 |
| K20 | DO3 | 7/8 | `Q200.3` | 备用 | 网络阀 375Y1 |
| K21 | DO0 | 1/2 | `Q201.0` | 无 | 主传动 STO |
| K21 | DO2 | 3/4 | `Q201.2` | 无 | 其余驱动 STO |

| 驱动 | STO？ | CN 路径 | EU 路径 |
|---|---|---|---|
| 主刀辊 PM240-2 | 是 | 305K1/330K1 触点 | K21 DO0 |
| 进料/出料/废料 i950 | 是 | 305K1/330K1 触点 | K21 DO2 |
| 油泵、风机 | 否 | 只停接触器 | 只停接触器 |
| 主接触器 | 否 | 标准 PLC | 标准 PLC |

| 名称 | 做什么 | 安全相关？ |
|---|---|---|
| STO | 封锁 IGBT 脉冲，自由停车 | 是 |
| Stop-Safe | 给 DF/安全中心的安全停止请求 | 是 |
| QUICK.STOP | 标准输出 `Q104.11` → Simotion DI2 的快停 | **否** |
| 主接触器 | 切断 400V，普通启停 | **否** |

> 线圈来源不同：`301K1/320K1` 跟随 `Q200.0`，`305K1/330K1` 跟随 `Q200.2`，`327K1/366K1` 跟随门链。三者不能互换。
>
> Stop-Safe 不是 STO：它只是“请求对方安全停”。QUICK.STOP 不是 STO：它是标准输出。主接触器不是 STO：它不满足防止意外启动的要求。

## E 安全 IO 映射：端子对与过程位
| 模块 | 通道 | 端子对 → 过程位 |
|---|---|---|
| EL1918 8DI | DI0–DI7 | 1/2→bit0、9/10→bit1、3/4→bit2、11/12→bit3、5/6→bit4、13/14→bit5、7/8→bit6、15/16→bit7 |
| EL1904 4DI | DI0–DI3 | 1/2→bit0、5/6→bit1、3/4→bit2、7/8→bit3 |
| EL2904 4DO | DO0–DO3 | 1/2→bit0、5/6→bit1、3/4→bit2、7/8→bit3 |

| 项目 | K10 | K11 | K12 | K13 | K14 | K15 | K20 | K21 |
|---|---|---|---|---|---|---|---|---|
| AISLING | EL1918 | EL1904 | EL1904 | EL1904 | — | — | EL2904 | — |
| ARAMIS | EL1918 | EL1904 | EL1904 | EL1904 | — | — | EL2904 | — |
| ALARIC | EL1918 | — | EL1904 | EL1904 | EL1904 | EL1904 | EL2904 | EL2904 |
| AUDRIC | EL1918 | EL1904 | EL1904 | EL1904 | — | — | EL2904 | — |

- FSoE 地址 = 卡号后缀：K10=10、K11=11、K12=12、K13=13、K14=14、K15=15、K20=20、K21=21。换卡后必须重拨 DIP。
- `405.x` 是机架概览，`PLCV 10–21` 是端子/过程位，箱柜清单的 Sheet 列也指向 405.x。
- 安全程序/安全继电器不在 IO 表里：IO 表只有 EL29xx 的过程位，Dold 线圈/触点和复位逻辑都在程序与 BOM 里。
- AISLING 的 BOM 把 EL1918 写成 K11，405 图写 K10；BOM 的 EL1904 物料号也与 405 图不同。**以 405 图/实物为准。**

## F 验证与排故：先量端子，再换件
| 上电前检查 | 做法 |
|---|---|
| Dold 型号 | UG 6929.60/100，851058828；301K1+301K5 或 320K1+320K5 成对 |
| 安全卡槽位 | 以 405 图为准，不以 BOM 为准 |
| FSoE 地址 | DIP 10/11/12/13/14/15/20/21 与项目一致 |
| 24V | EL29xx 电源、VS0–VS7 都有 24V |
| 双通道 | 每个门/急停/LOTO 两路都接，无短接片 |
| 门继电器 | 门全关线圈有 24V；开一扇门掉电 |
| STO | 复位后 STO_A/B、SIA/SIB 有 24V；急停后 0V |
| 安全中心 | XSAFCC1/2 12 芯连续，屏蔽/PE 正确 |
| 操作箱 | 34 芯无短路/断线，5NC 触点全动作 |
| LOTO | 两路都变化，客户侧接线确认 |

| 现象 | 可能原因 | 检查 |
|---|---|---|
| 安全继电器不吸合 | 急停未释放、门开、LOTO、安全中心 Stop、EL2904 无输出 | Q200.0、Dold A1/A3 |
| 门通道差异 | 门开关错位、电缆断、端子松 | EL1918 两路、XDR 端子 |
| 急停环断 | 5NC 触点坏、XESDF/XESHQ 电缆、327K1 触点 | XESDF 1–4、327K1 13/14 |
| STO 不释放 | 305K1/330K1 未吸合、DO2 无输出、SIA/SIB 0V | 继电器线圈、Q200.2、驱动端子 |
| 门锁不释放 | Q109.x 无输出、S6 请求未进、Lock control 断 | 标准 DO、I103.x、S6 |
| FSoE 不通信 | DIP 地址错、EtherCAT 线坏、24V 掉 | 地址 10–21、网线、电源 |

> 安全输入/输出禁止在标准 PLC 里强制、旁路、仿真。调试旁路只能用安全程序的正式 bypass，带计时、记录、审批。改线必须同步改安全程序和安全评估。

## G SV 变化检查表
| 变化 | 必改页 | 模块/端子 | 电缆/检查 |
|---|---|---|---|
| 单刀 → 双刀 | 加 315/316 | 第二组 STO；330K1 加 506.1/2 | 两套上刀辊是否独立 STO |
| CN → EU | 320 保留；删 330/366；加 560/565、375 | 加 K14/K15/K21；删 330K1/366K1 | WC580/581、门锁、直驱 STO |
| 加安全中心 | 560/565 | K14 EL1904；320K1 触点进 XSAFCC2 | 12 芯、急停 vs Stop-Safe |
| 加门锁 | 门页加 S1/S6/Q109.x | K209 标准 DO、K103 标准 DI | PUR 8x0.34、M12、5x0.34 |
| 加 LOTO | 380 页加 I203.0/1 | K13 DI0/1；X715 9/10 | 双通道、复位条件 |
| 改 DF/SR/AS | 510/525/540 | XESDF/XESHQ/XESSR/XESAS | 18G1.5、门继电器串环 |
| 3 扇 → 5 扇 | 加 361/363 | K10 通道够不够；不够加 K12/K15 | 门数跟出料架构走 |

变更前先问 8 个问题：

- 功能变了吗？
- 输入通道够吗？
- 输出通道够吗？
- Dold 型号和数量变了吗？
- 急停环端子/电缆变了吗？
- 复位条件变了吗？
- STO 端子变了吗？
- 安全评估覆盖了吗？

任何一项答不上来，就不要下单。
