HQ 的控制电源只有两条链：**24VDC 给“会思考的东西”**（PLC、安全、IO、驱动控制、阀、传感器），**230VAC 给“会发热/会亮的东西”**（柜灯、插座、风扇、小空调、主接触器线圈）。两条链各有自己的变压器/电源、端子编号和保护，混在一起看就会把 -X24D 的 0V 当成 +24V。

## A 两条链，先分清
```flow LR
(400V 3Ph) --> =LVS 400V 配电
=LVS 400V 配电 --> 24V PSU -101G1/-105G1
24V PSU -101G1/-105G1 --> =DCV 24V 分配
=DCV 24V 分配 --> PLC/安全/IO/阀/传感器

(400V L1/L2) --> -201T1 2500VA
-201T1 2500VA --> =ACV 230V 分配
=ACV 230V 分配 --> 柜灯/插座/风扇/小空调/主接触器线圈

(=LVS 400V) --> 400V 大空调/油泵/真空
```

| 链 | 电源 | 典型负载 | 保护 | 样本页 |
|---|---|---|---|---|
| 24VDC | 2×TDR-960-24，40A/960W | PLC、EL 模块、安全继电器、i950 控制、阀、传感器 | S201-C4/C6 | 101/105/131 |
| 230VAC | -201T1 2500VA，单相 | 柜灯、插座、风扇、500W 空调、主接触器线圈 | S201-C4/C6 + 3RV 9–12.5A | 201/215 |
| 400VAC | =LVS | 3.5kW 空调、油泵、真空风机 | 400V 分支 | 75/251/255/601/801 |

> 一句话：**24V 电源的输入是 400V 三相，不是 230V。** 230V 是另一台 2500VA 单相变压器，和 24V PSU 没有电气连接。

## C 24V 分配与端子
```tree
-DCV 24V
├─ -X24V 控制柜 (+13511/+13545)
│  ├─ +24V: 10-16 / 20-29 / 30-39 / 40-42 / 50-52 / 60-66
│  ├─ 0V:   510-516 / 520-539 / 540-552 / 560-566
│  └─ 0V-PE: 500-503 → -X24VN/-X24DN → -XPE
├─ -X24D 柜 3 (+13531)
│  ├─ +24V: 10-24
│  └─ 0V:   510-524
└─ -X24D 本地 (Driver)
   ├─ 500: PE
   └─ 501-503: 0V
```

| 编号 | 含义 | 记忆 |
|---|---|---|
| -X24V 10–16 | +24V，-105F4 C6 | PLC/IO |
| -X24V 20–29 | +24V，-106F1 C6 | 安全/控制 |
| -X24V 30–39 | +24V，-106F5 C6 | 按钮/操作箱 |
| -X24V 40–42 | +24V，-107F1 C4 | 阀/激光 |
| -X24V 50–52 | +24V，-107F5 C4 | 充电/放电/安全 |
| -X24V 60–66 | +24V，-108F1 C6 | 按钮/外部接口 |
| -X24V 5xx | 0V | 与同组 +24V 成对 |
| -X24D 500–503 | PE + 0V | **不是 +24V** |

> 0V 在 -XPE:1/2 用 GNYE 线一点接地（AISLING 26/PDF 12；ARAMIS 26/PDF 17；AUDRIC 12/PDF 10）。两台 PSU 的 0V 经 PE 变公共，但 +24V 各自独立；远程柜不能再把 0V 接到 PE。

## G 保护、选择性与故障顺序
| 项目 | 设计 | 风险 |
|---|---|---|
| 24V 分支 | S201-C4/C6 | PSU 恒流限流，C6 磁脱扣可能到不了；短路可能整段掉 |
| 24V 冗余 | 无 | 单 PSU 故障只影响本组；不是冗余 |
| 24V 0V | 经 -XPE 一点接地 | 两台 PSU 0V 经 PE 公共；远程柜不得重复接地 |
| 230V 变压器 | 2500VA，一次 9–12.5A，二次 C4/C6 | 分支之和 18–22A > 10.9A；无二次总保护 |
| 230V N-PE | 未画短接 | 二次浮地；单相接地不跳闸，无绝缘监测 |
| 插座 | 16A 插座 + C6 | 无 RCD；实际最大 6A |
| 远程 24V | 单只 C6，无本地分支 | 整柜掉电风险 |

| 故障 | 24V 控制 | 24V 驱动 | 230V | 结果 |
|---|---|---|---|---|
| 400V 总失电 | 掉 | 掉 | 掉 | 全停；安全/STO 掉；无控制停车 |
| 230V 失电 | 保持 | 保持 | 掉 | PLC 活；SQ-M+/HQ-M 主接触器线圈掉 → 传动停；可报反馈丢失 |
| -105G1 故障 | 掉 | 保持 | 保持 | PLC/安全掉；STO 掉；安全停机 |
| -101G1 故障 | 保持 | 掉 | 保持 | 柜 3 驱动控制掉；主接触器可能保持闭合，**需确认** |
| 24V 分支短路 | 可能整段掉 | 可能整段掉 | 保持 | 取决于短路在哪组 |

| SV 变化 | 改什么 | 注意 |
|---|---|---|
| 柜冷 water ↔ air | SCC 251/255/260；LVS 75 | 水冷加热交换器/水流检测；空冷加空调 230V 或 400V |
| 230V ↔ 400V 空调 | ACV F6；LVS 75 | 500W 走 230V；3.5kW 走 400V |
| AOC | RLS 297；DCV 106 | 24V 继电器 + 230V 灯 |
| CMC | 1920–1952；远程柜 13711/13730 | 额外 EL/24V 分支；三个样本没有 |
| 真空 | VAC 801/802 | 400V 风机 + 24V 控制 |
| 门锁 | STE 327；DCV 106 | 24V 继电器/电磁锁 |
| 激光 | VEL 701；DCV 107 | 24V 激光 -701U1；ARAMIS 201 端子 8 标签待确认 |
| EU ↔ CN | MPS；ACV 201 | EU 加 110kVA 主变压器；230V 抽头按 380/400/460V 改桥 |
| 单刀 ↔ 双刀 | DCV 101/102/115；ACV 201/205 | 多一套远程 24V + 230V + 空调 |
| 主接触器线圈 | LVS 61/62；DCV 102 | SQ-N 24VDC + C16；SQ-M+ 230VAC + F7 |

**待确认（按优先级）**

1. 24V 短路时 C6 是否能在 PSU 限流前跳闸；必要时改电子断路器。
2. 230V 二次侧 N-PE 到底是否浮地；浮地则要加绝缘监测。
3. 服务插座 16A 挂 C6、无 RCD；EU/CE 项目要加 RCBO。
4. ARAMIS 远程柜单只 6A、无本地分支；整柜掉电风险。
5. ARAMIS 10m 24V 电缆压降；调试测远程 -X24V 电压。
6. 柜 3 6A 馈线对 8 台 i950 的上电涌流；必要时改 C10/分两路。
7. -101G1 单电源故障时主接触器是否分断；安全状态要验证。
8. 控制柜 13511/13545 无 SCC 页；高温现场热计算。
9. ARAMIS 201 端子 8 “laser” 标签与实际 205 馈线不符；以 24V 激光为准。
10. 230V 变压器分支之和 > 额定；加负载前做容量/选择性校核。

> 新平台差异：新 HQ-M（ADARA/BELEN/ROCH）的 24V 分配分布在 +13501/+13511/+13531/+13541，`=DCV` 约 11 页；旧 AISLING 是 6 页。新项目先看柜号代际，再套负载表。
