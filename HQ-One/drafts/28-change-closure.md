改图只完成一半。EPLAN、报表、3401、SAP、PDF 必须指向同一版本。做法是：一个源、两个基线、三道比对、四道门。

## A 变更闭环全景
```flow LR
(变更请求) -> 影响分析
影响分析 -> EPLAN改图
EPLAN改图 -> 重生成报表
重生成报表 -> 3401核对
3401核对 -> ILC释放
ILC释放 -> SAP复核
SAP复核 -> PDF发布
PDF发布 -> 归档与记录
```

任何一步对不上，回到 EPLAN 改图。不要在下游文件里补。

| 数据 | 角色 | 判定 | 责任 |
|---|---|---|---|
| EPLAN 项目 | 唯一设计源 | 页、设备、端子、电缆、部件号完整 | 电气设计 |
| EPLAN 报表 | 图纸的汇总视图 | `&LAY`、`&CON`、`&WRE`、`&PLCV` 已重生成 | 电气设计 |
| 3401.xlsx | SAP BOM 导出 | 行、数量、单位、物料号、有效期对 | 电气/BOM |
| SAP BOM | 订单执行数据 | SO/item、组件、数量正确 | SAP 关键用户 |
| PDF | 交付与归档版本 | 页数、书签、图框、版本一致 | 电气/项目 |
| 变更记录 | 追溯证据 | 单号、影响、评审、日期、旧版位置齐全 | 项目 |

> 判定：每个下游文件都能指回同一个 EPLAN 版本。任何一份对不上，变更就没有关闭。

## B EPLAN 侧闭环
EPLAN 是源。报表是派生件。改完图，先让四类报表重新生成。

| 改动对象 | 必须更新的报表 | 核对字段 |
|---|---|---|
| 设备增删、移位、换部件 | `&LAY` 箱柜设备清单 | DT、Position、Part number、Sheet、Type、Safety relevant |
| 端子、端子排 | `&CON` 端子图 + 端子排总览 | 端子号、端板、终端固定、保护罩、标记卡、短接片 |
| 电缆、长度、走向 | `&WRE` 外部/内部电缆总览 | 电缆号、型号、长度、起止、部件号 |
| PLC 模块、IO 地址 | `&PLCV` 通道图 + `&BUSV` | 地址、信号名、去向页.列、模块型号 |
| 页、页号、页名 | Page tree、Page list、Device tree、Device tag list | 页数、书签、页名语法 |
| 安全器件 | `&LAY` 安全列 + 安全页 | X 标记、双通道、STO |

BHS 图纸没有独立的 `&RPT` 报表文档。BOM 报表就在 `&LAY` 的箱柜设备清单。

一条链：页名 `&WDA==GEN=MPS+13501 HQ/10` 给出功能组、柜号和页号。设备标签 `-10Q1` 跟着页号走。`&LAY` 的 Sheet 列回到 `10.1`。3401 行和 SAP 位置行都挂在这个柜号下。

| 书签 | 作用 | 变更后看什么 |
|---|---|---|
| Page tree | 文档类型→功能组→柜→页 | 新页在正确功能组和柜下 |
| Page list | 全部页平铺 | 页数、页名、页序 |
| Device tree | 结构→柜→字母→设备 | 新设备在正确柜 |
| Device tag list | 全部标签平铺 | 新标签唯一、旧标签无残留 |

> 示例：AISLING 的箱柜设备清单在 PDF 145–147（+13501）、150–154（+13511）、156–159（+13531）、163（+13715）。这是模板页位，不是固定页码。

## C BOM 侧闭环
3401 是 SAP 导出，不是源文件。改完图，重新导出 3401，与旧版逐行对比。

| 变更类型 | 3401 里看什么 | 常见错 |
|---|---|---|
| 新增物料 | 新行在正确 E/I 或 `E_135xx` 分支 | 漏挂分支、数量为 0 |
| 删除物料 | 旧行消失，数量汇总正确 | 只删图纸没删 BOM |
| 数量变更 | `Comp. Qty (CUn)` 是每父件用量 | 把总用量当每父件用量 |
| 物料号替换 | `Component number` 与描述同时变 | 只改描述没改号 |
| 单位变更 | `Component UoM`、`Base Unit` | 把 M 当 PC、把 KG 当 PC |
| 有效期/状态 | `Valid from`、Material Status | 用过期、冻结或未扩展工厂的料 |

```tree list
3401 电气相关分支
  CONTROL
    E_13501 主进线柜
    E_13511 控制柜
      E_13511_X PLC/IO 扩展
    E_13531 驱动柜
      E_13531_X 驱动扩展
    E_13715 操作面板
  机械总成分支
    E042CO0001–0006 各总成电气
    I042CO0001–0006 各总成安装材料
  UNASSEMBLED PARTS
    E042CO00LP 现场散件
```

| 现象 | 先查 | 处理 |
|---|---|---|
| 图纸有、3401 无 | 物料号是否 Assign、是否 irrelevant、工厂/有效期/状态 | 补主数据，或改 EPLAN 后重释放 |
| 3401 有、图纸无 | 是否旧 BOM 残留、重复 DT、客户供货 | 走变更删除，不手改 3401 |
| 数量不符 | 重复行、重复 DT、电缆长度、每父件用量 | 回 EPLAN 修正后重释放 |
| 物料号不对 | 描述、制造商、工厂 | 换号，或修 EPLAN 部件库 |
| 单位不符 | PC、M、KG | 改 EPLAN 单位或电缆长度 |

> 3401 和 SAP BOM 都不是改图入口。要改，回 EPLAN 改源，再重释放。

## D SAP/ILC 侧闭环
变更释放和首次释放不是一回事。已有 BOM 时，先判断是改还是建。

| 场景 | 操作 | 禁止 |
|---|---|---|
| 首次释放 | `Assign SO Position/BOM`、`Assign`、`Assign SO Material`，最后 `Create BOM` | 跳过 relevance 判断 |
| 已有 BOM 的变更 | `Change/Synchronize` 或 SAP 变更事务 | 再次 `Create BOM` |
| 只换一个物料 | 旧行设 irrelevant 或删除，新行 Assign | 只改描述、不改物料号 |
| 只改数量 | 重算 Count，再同步 | 在 SAP 里直接加行 |
| 挂错 SO/item | `Remove SO position descending` 后重挂 | 只改 SO 列 |
| BOM 被锁 | 等锁释放，或找 SAP 管理员 | 反复点击、强退 |
| 重复 BOM | SAP 比较后清理 | 未授权就删 BOM |

`Change/Synchronize` 的适用条件按公司 SAP 流程，待确认。

| # | 释放前检查 | 通过标准 |
|---|---|---|
| 1 | 项目与版本 | 与变更单、图纸版本一致 |
| 2 | 位置与订单 | 每个位置有 SO + item |
| 3 | 子行物料 | 用 `Assign` 补齐每个 relevant 子行的物料号 |
| 4 | 父行物料 | 每个位置有汇总物料 `E_xxxxx` |
| 5 | BOM 相关性 | `BOM relevant` 保持、`BOM irrelevant` 变灰 |
| 6 | 错误 | 无空白、无红色行 |
| 7 | 一图多 Item | 已按位置分挂 |
| 8 | 记录 | 变更号、操作人、日期已填 |

释放后做四件事：`CS03` 查 BOM；与 3401 对比；确认无重复、无锁；用 `Terminate process`（结束进程）退出并记录。

> Change number 何时必填，按公司 SAP 变更流程。首次释放可留空。具体规则待确认。

## E PDF/版本侧闭环
PDF 是交付件，也是导出件。只从 EPLAN 导出，不手改。

| 检查 | 判定 |
|---|---|
| 页数 | 图框 Number of pages 等于 PDF 页数；Page list 条目 = PDF 页数 + 1 |
| 书签 | Page tree、Page list、Device tree、Device tag list 四类齐全 |
| 页名 | `&WDA==GEN=MPS+13501 HQ/10` 各段正确 |
| 图框 | 客户、地点、图号、主设备号、版本、订单/Item 正确 |
| 版本 | 版本号按公司规则递增，修改日期正确 |
| 内容 | 无空交叉引用、无问号、无旧柜号残留 |
| 文件 | 文件名、目录、命名规则与订单一致 |

| 对象 | 新版本 | 旧版本 |
|---|---|---|
| EPLAN 项目 | 冻结为发布版，保留可回退副本 | 只读存档 |
| PDF | 发布到交付目录 | 移入作废目录，停止发放 |
| 3401 | 新导出，用于本次核对 | 旧导出保留作对比 |
| SAP BOM | 新 BOM 或新更改号 | 按 SAP 有效期和更改号管理 |
| 变更记录 | 新记录，关联旧记录 | 只读，不覆盖 |

> 旧版 PDF 不回收，现场就会按旧图接线。新版本发布时，同时作废旧版。

修改人、审批人和旧版归档路径没有统一图框字段。按公司实际流程填写，待确认。

## F 一份图纸多个 Item
一份图纸可以给多个 SO item 供货。3401 只是其中一个 item。

ILC 教程示例（SO 0020548551）：

| 位置 | SO item | 汇总物料（示例） |
|---|---|---|
| 13501 / 13511 / 13531 | 3403 | E_13035、E_18619 等 |
| 13033 | 1001 | E_13033 |
| 13034 | 1701 | E_13034 |
| 13050 | 1002 | E_13050 |

汇总物料按位置实际指定。表中 `E_xxxxx` 只作示例。

1. 先做位置→item→汇总物料对照表。
2. 按供货范围拆 item：柜、功能段、独立设备。
3. 每个位置父行单独 `Assign SO Position/BOM`。
4. 每个位置单独 `Assign SO Material`。
5. 子位置同 item 才用 `SO Position from parent`。
6. `Create BOM` 前逐位置核对三元组。
7. 每个 item 单独导出 3401 核对。

| 错误 | 后果 |
|---|---|
| 批量 Apply 同一个 item | B 项物料挂到 A 项 |
| 复制上一行的汇总物料 | 父项跟着错 |
| 按页数拆 item | BOM 与供货范围不符 |
| 只看 3401 主 item | 漏 RS1–RS5、stacker 等独立 item |
| 子位置盲目继承 | 整棵子树挂错 |

> 示例中的 item 号来自 ILC 教程截图。实际拆分按订单配置和供货范围确定。

## G 变更记录模板
变更记录是下一次变更的基线，也是追溯证据。

| 字段 | 填写内容 |
|---|---|
| 变更单号 | ECN/BCN 唯一号，关联 SAP Change number |
| 变更原因 | 客户变更、SV 变更、设计纠错、物料替代、标准变更 |
| 变更类型 | 加页、删页、换型、换料、改数量、改端子电缆 |
| 影响功能组/页 | `=MPS`、`=LVS`、`=STE` 等；EPLAN 页号；PDF 页 |
| 影响设备 | 新增、修改、删除的设备标签 |
| 影响端子/电缆 | 端子排、电缆号、长度、起止 |
| 影响物料 | 旧物料号→新物料号；数量；单位 |
| 影响 SO/item | 哪些位置挂哪个 item |
| 图纸版本 | 改前/改后版本、图号、页数 |
| PDF 版本 | 版本号、导出日期、修改人 |
| SAP 更改号 | Change number、BOM 创建/更改日期 |
| 评审 | 自检、互检、安全评审、释放评审的签字和日期 |
| 释放日期 | 图纸、报表、3401、SAP、PDF 各自日期 |
| 旧版归档 | 路径、文件名、作废标记 |
| 遗留项 | 未关闭问题、待确认项、责任人 |

ECN 与 BCN 的关系和编号规则按公司流程，待确认。

| 最小证据包 | 内容 |
|---|---|
| EPLAN | 改前/改后项目副本或版本标签 |
| PDF | 旧版和新版各一份 |
| 3401 | 旧导出和新导出各一份 |
| ILC | 释放截图或释放记录 |
| SAP | `CS03` BOM 截图 |
| 变更单 | 签字版，含影响清单 |

## H 常见错误
| 现象 | 后果 | 根因 | 堵漏 |
|---|---|---|---|
| 只改图纸不改报表 | 箱柜清单、端子、电缆仍旧 | 把报表当自动更新 | 改图后四表重生成 |
| 只改 BOM 不改图纸 | SAP 有、图纸无 | 把 3401 当源文件 | 任何 BOM 变更回 EPLAN 找源 |
| 重复释放 | 重复组件、数量翻倍 | 同一 item 重复 2 次 `Create BOM` | 先查已有 BOM，用 Change/Synchronize |
| 旧版 PDF 继续流通 | 现场按旧图接线 | 旧版未作废、未回收 | 发布新版时同步作废旧版 |
| 物料号失效 | Assign 空白、BOM 缺件 | 状态 95/98/99、有效期过期、工厂未扩展 | 释放前查主数据 |
| 一图多 Item 未拆 | BOM 挂错订单 | 批量 Apply、图省事 | 先做位置-item-汇总物料表 |
| 父行/子行混选 | 汇总物料错、组件漏 | 选错层级 | 父行挂 SO 和物料组，子行 Assign |
| 手改 PDF 或 3401 | 下次变更丢失、无法追溯 | 把导出件当源文件 | 只改 EPLAN 源 |
| 未正常退出 | 锁、残留进程 | 直接点窗口 X | 用 `Terminate process`（结束进程）退出 |
| 旧柜号残留 | 找错柜、挂错位置 | 复制模板未清旧号 | 全文搜 13505/13545/13515 |

> 五份数据加一份记录，全部指向同一版本，才算改完。
