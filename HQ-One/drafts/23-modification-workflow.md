应届生能改图，但不能只凭 SV 改图。SV 说明客户要什么，EPLAN 说明怎么做。两者之间隔着模板、页号、端子、电缆和 BOM。

## A 先回答：能不能只凭 SV 改图

| 任务 | 级别 | 条件 |
|---|---|---|
| 改项目名、客户、地点、订单号、图号 | ok 可独立 | 与订单和封面一致；不改结构 |
| 复制已有页 | ok 可独立 | 同机型、同柜号、同标准；复制后逐页核对 |
| 改文本、地址注释 | ok 可独立 | 不影响标签、端子、电缆、BOM |
| 按模板加一页选配 | warn 需复核 | 有对照项目；师傅逐页复核；只加一个完整功能页 |
| 改设备标签 | warn 需复核 | 保持前缀规则；查交叉引用和 BOM |
| 改端子、电缆号 | warn 需复核 | 查端子排、电缆清单、线号 |
| 改 IO 地址 | warn 需复核 | 查 PLCV、IO 表、软件 |
| 改 BOM 物料 | warn 需复核 | 查箱柜清单、ILC |
| 改安全回路的文字或注释 | warn 需复核 | 只改文字；逻辑变更升级 |
| 改安全链、STO、急停、门锁 | no 必须评审 | 双通道和安全继电器由师傅确认 |
| 改主传动功率、驱动、电机 | no 必须评审 | 电机、变频器、电缆、保护一起算 |
| 改柜体、母排、电容、直流母线 | no 必须评审 | 温升、短路、爬电距离要复算 |
| 改 EU/CN 标准、电压、认证 | no 必须评审 | 名称牌、主配电、认证文件全变 |
| 改双刀架构、柜号体系 | no 必须评审 | 页树、IO、安全门全变 |

> 能独立不等于能释放。任何改动都要过自检和互检；涉及安全时加安全评审。

## B 改图七步法

```flow LR
(SV变更) -> 影响分析
影响分析 -> 找最近模板
找最近模板 -> 复制或修改页
复制或修改页 -> 改设备标签与交叉引用
改设备标签与交叉引用 -> 改端子电缆线号
改端子电缆线号 -> BOM/ILC
BOM/ILC -> {评审门}
```

| 步 | 做什么 | 输出 | 停手条件 |
|---|---|---|---|
| 1 SV 变更 | 标出变更行和旧值 | 变更清单 | 涉及安全、主传动、标准 |
| 2 影响分析 | 查功能组、页、器件、端子、电缆、BOM、安全 | 影响清单 | 找不到先例 |
| 3 找模板 | 同机型、同柜号、同驱动、同选配 | 参考项目 | 只有页数接近 |
| 4 复制或修改页 | 复制完整功能页，再改内容 | 新页或改页 | 跨文档块未同步 |
| 5 标签与交叉引用 | 改设备标识，更新引用 | 标签一致 | 出现空引用或问号 |
| 6 端子、电缆、线号 | 改 CON、WRE、线号 | 端子表、电缆表 | 端子排缺页 |
| 7 BOM/ILC | 生成箱柜清单，释放 SAP BOM | SAP BOM | 物料号缺失 |

EPLAN 操作要点：

| 操作 | 做法 | 检查点 |
|---|---|---|
| 复制页 | 页导航器选中页，Ctrl+C 和 Ctrl+V，选新页号 | 页名、结构、页码正确 |
| 复制项目 | 项目 → 复制；只复制参考项目 | 项目名、图号、订单号已替换 |
| 改设备标签 | 设备属性改完整设备标识 | 前缀等于主功能页；无重名 |
| 更新交叉引用 | 更新连接和交叉引用 | 无空引用、无问号 |
| 端子排 | 项目数据 → 端子 → 端子排 | 端子号、短接片、端板齐全 |
| 电缆 | 项目数据 → 电缆 → 电缆编辑 | 型号、长度、起止点齐全 |
| 报表 | 工具 → 报表 → 生成箱柜设备清单 | 行数、部件号、数量、安全标记 |
| BOM/ILC | SAP 选项卡 → Filter → Material management → Create BOM | 位置、SO Item、物料号齐全 |

> 不要手改 PDF。PDF 只是导出件；改 EPLAN 源项目，再重新导出。

> ILC 的完整顺序见 [10 EPLAN→SAP](10-sap-ilc.html)。

## C 影响分析：先查七类，再找模板

```tree
影响分析
  功能组 | 哪些 =MPS、=LVS、=STE、=KNB 页受影响
  页 | 新增、删除、替换；页号和 PDF 页序
  器件 | 设备标签、型号、部件号、柜内位置
  端子 | 端子排、端子号、短接片、端板
  电缆 | 电缆号、型号、长度、起止点
  BOM | 箱柜清单、数量、安全相关标记
  安全 | 急停、门锁、STO、安全继电器
```

| 新订单特征 | 最近模板 | 页数 | 先看什么 |
|---|---|---|---|
| SQ-M+，有 Splice | AZARIA / BRISEIS | 234 | SPD 750 |
| SQ-M+，无 Splice | ANWEN | 233 | 只少 SPD 750 |
| SQ-M+，加 CMC 和真空 | ANSEL | 249 | CMC 1920–1952、VAC 801 |
| HQ-M，45 kW | ALARIC / DALIAH | 346 / 336 | 驱动 132 kW、STO |
| HQ-M，60 kW 加 Waste | ARLEN | 340 | 驱动 200 kW、WEV |
| HQ-M，60 kW 加出料站和堆码机 | ARAMIS | 373 | OUS、Stacker、3 扇门 |

> 页数接近不等于同模板。SAANA 335 页，DALIAH 336 页，标题相似度只有 0.48。

## D 案例 A：无 Splice → 有 Splice

```flow LR
(ANWEN 233) -> 加 SPD 750
加 SPD 750 -> (AZARIA 234)
```

| 维度 | 变化 | 证据 |
|---|---|---|
| SV | `Splice Detection` 空 → Yes | 20543109 对比 20553680 |
| 图纸页 | 只多 1 页 | `&WDA==GEN=SPD+13511 HQ/750`；相似度 0.9979 |
| PDF 页序 | 第 73 页插入；之后 PDF 页 +1 | EPLAN 页号不变 |
| 器件 | `-750B2` 传感器 171641.04 | 安装位置 `+13000` Machine |
| 端子与 IO | `-XSPD` 1/2/3；`-405A1-K140` DI4 | EL1258；`I140.4`；`&PLCV/140.4` |
| 电缆 | `-W13366` JZ-500 4G1.5 60 m；`-W13365` 5 m | 851164513；174261400 |
| BOM | XSPD 行 Position 131、Sheet 750.2 | K140 已在箱柜清单；传感器和两根电缆未检出 |

> 只复制 WDA 750，会漏 XSPD 端子页、PLC 地址和电缆。传感器 BOM 要单独补。

## E 案例 B：2×45 kW → 2×60 kW

| 维度 | ALARIC 346 页 | ARLEN 340 页 |
|---|---|---|
| 主传动 | 2×45 kW；132 kW/250 A；851258399；70 mm² | 2×60 kW；PM240-2 FSG 200KW；851247517；2/0 AWG |
| 进线保护 | 51F1 160 A NH00；95 mm² | 51F1 与 51F7 2×200 A NH1；2/0 AWG |
| 主接触器 | 90 kW | 132 kW |
| 安全 | STO 310 管主传动；无柜锁 | STO 305 主传动，306 驱动组；300/310/318/325 柜锁 |
| 选配 | 无 Splice、无 Waste | SPD 750；WEV 1700/1705/1750/1760/1780 |
| 电容与母线 | 1030 充电、1050 放电、1080 电容；KNB 1320 DC bus | 1030 电容单元；无 1320 DC bus |

页级差异：

- 删除 LVS 58。
- 新增 STE 300/318/325；310 改为柜锁。
- STO 从 310 改为 306。
- 新增 DEX 500/542/544；删除 DEX 548–550。
- 新增 VEL 701–703；删除 725/735。
- 新增 PLCV 105/205、BUSV 5 Profinet。

> 这是安全链和主传动的双重变更。必须做安全评审和驱动参数复核。

## F 案例 C：加 CMC / Cut-to-Mark

| 维度 | 变化 | 证据 |
|---|---|---|
| SV | Cut-to-Mark 加真空 | AZARIA 234 → ANSEL 249 |
| 图纸 | CMC 1920/1927/1930/1950/1951/1952 | DEX 585/590；VAC 801；OUS 1696；PLCV 107/208 |
| 柜号 | 新增 `+13711`、`+13730` 远程箱 | 只在 DEX 和 1 页 CON 出现；无 LAY/BOM |
| 器件 | `-1915K1`、`-1927B1`、`-1920Y1`、`-1950T1`、`-1950M1` | 851086002；650142.05；-1920Y1 查清单；851129369；851239155 |
| 传感器 | `-1951B1`–`B3`、`-1952B1` | 851060083；电缆 851164489 |
| 端子与电缆 | `XLSC`、`XCLEAN`、`XPOS1`–`4` | 851164840；851164695；851239163/851239160 |
| BOM | BOM/20536199 有 851086002、851129369、851060083 | 650142.05 与真空件 801Q1/801M1/1696Y1 未检出 |

> CMC 跨 WDA、PLCV、LAY、CON 四个文档块。只复制 6 页电路，PLCV、端子、布局和 BOM 都会漏。851239155 是 -1950M1 伺服电机，不是清洁阀 -1920Y1。

## G 评审门、常见错误、停手清单

| 门 | 谁 | 检查项 | 不通过 |
|---|---|---|---|
| 自检 | 改图人 | SV 逐项、页 diff、标签、端子、电缆、BOM、安全 | 回到第 4 步 |
| 互检 | 另一电气工程师 | 与参考项目逐页对比、页号、交叉引用 | 回到第 4 步 |
| 安全评审 | 师傅或安全负责人 | 安全链、STO、急停、门锁、安全 BOM | 停止释放 |
| 释放前 | 项目或电气主管 | EPLAN 版本、PDF 一致、ILC BOM、一图多 Item | 不释放 |

| 常见错误 | 后果 | 正确做法 |
|---|---|---|
| 只改电路页 | 端子、电缆缺页，现场不能接线 | 同步改 CON 和 WRE |
| 标签前缀乱改 | 交叉引用和 BOM 对不上 | 前缀等于主功能页 |
| 旧柜号残留 | 现场走错柜 | 全文搜旧柜号 |
| BOM 未同步 | SAP 缺件或错件 | 重新生成箱柜清单 |
| 安全链被短接 | 安全评审不通过 | 恢复双通道，找师傅 |
| 复制后引用旧项目 | 跳转到旧页 | 更新引用并逐条点开 |
| 一图多 Item 未拆 | BOM 挂错订单 | 按位置逐 Item 挂 |

什么时候停手：

- 改安全链、STO、急停、门锁、安全继电器。
- 改主传动功率、驱动型号、电机数量。
- 改柜体、母排、电容、充电放电、直流母线。
- 改 EU/CN 标准、电压等级、认证、名称牌。
- 改双刀或单刀架构、柜号体系。
- 改客户接口协议：DF、SR、AS、KQ、堆码机。
- 参考项目找不到先例。
- 需要短接或屏蔽安全信号才能调试。
