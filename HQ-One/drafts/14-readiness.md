先给结论：**不能只凭 SV 独立改图。** SV 只说明“要什么配置”，不说明“电怎么接、端子怎么排、安全链怎么闭环、BOM 怎么同步”。应届生可以在“已有模板 + 最近对照项目 + 师傅评审”的条件下做受控修改；独立改图需要 6–12 个月的项目积累。

## A 结论：三级能力模型
| 级别 | 能做什么 | 监督要求 | 典型时间 |
|---|---|---|---|
| L1 读图 | 找到页、读懂回路、追一条信号、核对 BOM | 自学 + 抽查 | 1–4 周 |
| L2 受控改图 | 复制模板页、改项目标识/文本、加一个成熟选配页、改端子/电缆号 | 每步有对照项目，师傅逐页复核 | 2–6 个月 |
| L3 独立改图 | 改主传动/安全链/柜体/标准，处理客户接口与首次配置 | 安全评审 + 设计评审 | 6–12 个月 |

```flow LR
(读图L1) --> 受控改图L2: 有模板/有对照
受控改图L2 --> 独立改图L3: 安全/传动/标准
独立改图L3 --> 带新人
```

## B 为什么 SV 不够
| SV 给了什么 | SV 没给什么 | 直接改图的后果 |
|---|---|---|
| 机型、幅宽、操作侧 | 具体页号、设备标签、端子号 | 不知道从哪页改、改完交叉引用断 |
| 主传动功率、刀梁材质 | 驱动模块型号、电缆长度、编码器分度 | 驱动器/电缆选错，现场装不上 |
| 柜冷 water/air | 电源分配、熔断器、接触器、母排 | 24V/400V 负载超载或保护不匹配 |
| 选配 Yes/No | 选配回路、IO 地址、DEX 信号 | 只加了一页电路，端子/电缆/BOM 没加 |
| 电气标准 EU/CN | 认证、线色、电压/频率、安规距离 | 标准不符，客户验收不通过 |
| 特殊变体文字 | 机械/电气接口细节 | 按字面改，实际无法施工 |

> 一句话：SV 是“配置合同”，图纸是“施工图”，中间隔着一层“电气实现”。这一层就是本套 15–23 页要补的内容。

## D 任务分级：哪些能自己做
| 任务 | 能独立做？ | 前置条件 | 必须谁看 |
|---|---|---|---|
| 改封面/项目名/图号 | ok 可以 | 对照项目、版本正确 | 自检 |
| 复制一页成熟选配页 | warn 受控 | 有同配置历史项目 | 师傅逐页 |
| 改设备标签/页号前缀 | warn 受控 | 懂页号规则、全图搜旧标签 | 师傅 |
| 改端子/电缆/线号 | warn 受控 | 有端子图/电缆图对照 | 师傅 |
| 改 DI/DO/AI/AO 地址 | warn 受控 | 懂 IO 表、PLCV、程序接口 | 电气+软件 |
| 加传感器/选配 | warn 受控 | 有成熟模板、IO/BOM 同步 | 师傅+采购 |
| 改 24V/400V 配电 | no 禁止独立 | 会算负载/选择性/电缆 | 电气主管 |
| 改主传动功率/驱动 | no 禁止独立 | 会算惯量/功率/电缆 | 传动+设计评审 |
| 改安全链/STO | no 禁止独立 | 功能安全培训 | 安全评审 |
| 改 EU/CN 标准 | no 禁止独立 | 认证/安规知识 | 设计+认证 |
| 双刀改单刀/反之 | no 禁止独立 | 整套模板/柜号/页树 | 设计评审 |

## E 允许 / 禁止 / 必须评审
| 类型 | 例子 | 规则 |
|---|---|---|
| ok 允许独立 | 项目标识、注释、文本、PDF 导出 | 自检 + 版本记录 |
| warn 受控修改 | 加一页成熟 SPD/VEL/门锁、改一个传感器 | 有对照项目，师傅逐页复核 |
| no 禁止独立 | 安全链、主传动、母排、标准、双刀架构 | 必须设计/安全评审 |
| no 禁止 | 短接安全通道、绕过 STO、手改 PDF 代替 EPLAN | 任何情况下都不允许 |

## F 从应届生到受控改图
```timeline
第 1 周 | 读图 | 01/04/15/16/17，能独立找到页和端子
第 2 周 | 读订单 | 06/07/08，能把 SV 翻译成配置画像
第 3 周 | 读接口 | 18/19/20/21/22，能追一条完整信号链
第 4 周 | 跟做 | 在师傅旁边改一个成熟选配，做自检
第 2 个月 | 受控改图 | 独立改 1–2 个 L2 任务，师傅逐页复核
第 6 个月 | 复杂改图 | 主传动/安全/标准，参加设计评审
```

| 评审门 | 谁参加 | 看什么 | 不通过会怎样 |
|---|---|---|---|
| 自检 | 改图人 | 页/标签/端子/电缆/BOM 一致性 | 退回 |
| 互检 | 同组工程师 | 对照项目差异、交叉引用 | 退回 |
| 安全评审 | 安全/电气主管 | 急停/门/STO/双通道 | 不得释放 |
| 释放评审 | 项目/电气/采购 | BOM/ILC/交期 | 不得下单 |

## G 改图前必须回答的十个问题
1. 这次 SV 变化对应哪个功能组、哪几页？
2. 最近的同配置历史项目是谁？差异页有哪些？
3. 是单刀还是双刀？柜号组是 13501、13505、13515 还是新 HQ-M 13501？
4. 400V 侧的主开关/接触器/熔断器/电缆够不够？
5. 24V 侧电源容量、分路熔断器、端子够不够？
6. 安全链是否受影响？双通道是否完整？
7. 新增/修改的 IO 地址、PLCV 页、程序接口是什么？
8. 驱动器/电机/编码器/制动电阻是否匹配？
9. 端子、电缆、线号、BOM 是否同步？
10. 谁做互检/安全评审？释放记录在哪里？
