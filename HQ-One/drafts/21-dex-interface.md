DEX 是 HQ 与外部世界的硬线边界。PLC 通道先到端子，再经光耦或继电器、电缆去对端。看懂 DEX，先看端子，不看页名。

## A DEX 是什么
DEX = Data Exchange，EPLAN 功能组 `=DEX`。它只做三件事：隔离、转换、端子过渡。

| 版本/项目 | DEX 页 | 差异原因 |
|---|---:|---|
| py 模板 | 44 | 全选配（p.54–97） |
| AISLING SQ-M+ | 14 | 3 柜、单刀、简单 AS |
| ARAMIS HQ-M | 17 | 4 柜、双刀 |
| ALARIC HQ-M | 25 | 双刀、AS-A、安全中心 |

页号 503–575 是预留回路号，中间有空洞。14/17/25 是实际生成页数。

> 新平台差异：新 HQ-M（ADARA/BELEN/ROCH）的 `=DEX` 约 40 页（PDF 74–113），旧 AISLING 14 页、ARAMIS 17 页。新项目不要按旧页数找 DEX，先看页树 `=DEX` 段。

> `py` 指参考双刀模板，不是本批 HQ-PDF 项目。

```tree
DEX 页
  柜间 503-508
  对端 510/525/540/518-519/551-552
  操作盒 570-575
  选配 542-550/560-565
```

## B 隔离链：光耦与继电器
```flow
PLC 输出 -> 光耦/继电器 -> 端子 -X5xx -> 电缆 -WCxxx -> 对端 -XESxx
```

| 元件 | 物料 | 用途 |
|---|---|---|
| WAGO 光耦 | 851153522 | 快脉冲、安全、80 ms Good Cut |
| Finder 48 | 851086002 | 一般状态，2 组转换，8 A |
| Finder 58 | 851085974 | 资料称 4 组转换；订单未检索到，待确认 |

规则：快信号走光耦，慢信号走继电器。光耦线圈页和触点页分开画。

> 例：KQ AOC 的线圈在 519，触点在 518。只量一页，容易误判。

> 矩阵是信号字典，不是接线表。图纸没有的名字，不要硬找。

急停环：HQ 把干部急停分给 DF、SR、AS，再汇总回送 DF。端子是 `-XESDF/-XESSR/-XESAS/-XESHQ`。电缆是 `-WC461/-WC571/-WC591`。

STO 不走 DEX。它走 `=STE` 和 EL2904，再到 `-305K1`。Stop-Safe 走安全输出，也不经普通光耦。

## E 硬线 vs PROFINET
```flow LR
C6015 -> PN -> Lenze i950
C6015 -> ECAT -> EL 站 -> DEX
```

| 链路 | 内容 | 是否经 DEX |
|---|---|---|
| EtherCAT | C6015 与 EL 站 | 否 |
| PROFINET | 订单、AOC、飞剪、切数、故障 | 否 |
| 24 V 硬线 | 急停、状态、脉冲、模拟量 | 是 |
| 安全链 | 急停、门、STO、Stop-Safe | 部分经安全端子 |

| PN_Com 工作表 | 地址 | 方向 |
|---|---|---|
| `S7_to_Lenze` | `LPort64In8…15` | PLC → Lenze |
| `Lenze_to_S7` | `LPort64Out8…15` | Lenze → PLC |

`In` 是 Lenze 的输入，`Out` 是 Lenze 的输出。`S7` 是遗留角色名。AISLING 主控是 C6015。

| 对端 | 端子 | 电缆 |
|---|---|---|
| DF | -XESDF | -WC461 |
| SR | -XESSR | -WC571 |
| AS | -XESAS | -WC591 |
| CCD | -XCCC | -WC666 |
| KQ | -XKQ | -WC560 |
| 操作盒 | -X715 | -380WCS1 |
| 柜间 | -X531/-X511 | -503WC1 |

## F 排故：五步与三例
```flow LR
看端子 -> 分侧 -> 对页 -> 查链 -> 查驱动
```

| 现象 | 路径 | 先量 |
|---|---|---|
| Good Cut 丢失 | Q100.0 → 543 -543K3 → 540 XESAS 16/17 → WC591 | XESAS 16/17 脉冲 |
| DF 急停不复位 | XESDF 1–4/5–6 → -327K1 → K11 I201.2/3 → WC461 | 双通道 24 V |
| KQ AOC 不切 | Q102.9/10 → 519 -519K1/K2 → 518 XKQ 1/2 → WC560 | XKQ 1/2 触点 |

> 519 页标题写 e-stop，内容是 AOC 切。按端子找页，不按标题找页。

SR 速度若选配：先量 EL4074 CH00 的 0–10 V，再查转换器，最后量 SR 侧 0–20 mA。400 m/min 对应 16 mA。三份订单未画这段，遇到时以项目图为准。

## G SV 变化 → DEX 改什么
| SV 变化 | DEX 改什么 | 页/端子 |
|---|---|---|
| CCD 改 EXT | 新增第三方页或改 551/552 | XCCC / WC666 |
| AS 改 AS-A | 加 543、545–550 | XASM_AOC/_ES |
| SR 换刀选配 | 加 SR 接口页 | XESSR |
| 新增 KQ | 加 518/519 | XKQ / XRDAOC / WC560 |
| CMC 选配 | 无标准页，需新增 | CMC I/O |
| 真空选配 | DEX 不变 | OUS/INF |
| 单刀改双刀 | 柜间 3 页变 6 页 | X515 / X525 |
| 安全中心 | 加 560/565 | XSAFCC / WC580 |

检查表：

1. SV 选项是否改变对端清单。
2. 新对端是否有现成 DEX 页。
3. 端子数、电缆芯数是否够，是否留备用芯。
4. 快信号选光耦，慢信号选继电器。
5. 急停环是否闭合，双通道是否保持。
6. CON、WRE、BOM、PLCV 是否同步。
7. 页号是否唯一，是否残留旧柜号。
8. 是否更新测试清单。
