## G 评审门与常见错误
| 评审门 | 谁签字 | 不通过的处理 |
|---|---|---|
| 自检 | 改图人 | 退回修改 |
| 互检 | 同组工程师 | 退回修改 |
| 安全评审 | 安全/电气主管 | 不得释放 |
| 设计评审 | 电气主管/项目 | 不得释放 |
| 释放评审 | 项目/采购 | 不得下单 |

| 常见错误 | 后果 | 预防 |
|---|---|---|
| 只改电路页，不改端子/电缆 | 现场接不上 | 用 22 页检查表 |
| 设备标签页号前缀错 | 交叉引用错 | 全图搜索旧标签 |
| 旧柜号 13505 残留 | 找错柜 | 以 `+` 结构为准 |
| 24V 负载增加但电源没换 | 电源过载 | 算负载余量 |
| 安全双通道只接一路 | 安全失效 | 安全评审 |
| STO 当 Stop-Safe | 停不住/不合规 | 按 17 页区分 |
| IO 地址与程序不一致 | 动作错 | IO 表/PLCV/程序三方核对 |
| BOM 未同步 | 缺料/错料 | ILC 前逐分支核对 |
| 一份图纸多 Item 未拆 | BOM 挂错 | 按 Item 分别挂 |
| 手改 PDF 不回 EPLAN | 下次改图丢改动 | 只改 EPLAN 源项目 |
