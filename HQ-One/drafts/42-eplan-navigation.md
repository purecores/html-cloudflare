EPLAN 导出的 PDF 自带上万条内部链接。学会点箭头，就不用在 233 页里翻。本页给真实页号，照着重走一遍就会。

## A 页面的坐标系
| 元素 | 事实 | 用法 |
|---|---|---|
| 页面尺寸 | 1190 × 842 pt 横版 | 打印 A3 |
| 顶部列号 | 0–9，共 10 列 | `/51.2` 指第 51 页第 2 列 |
| 页地址语法 | 文档 + 功能 + 位置 + 页.列 | `=RLS/292.2` |
| 内部链接 | 每份 PDF 约 1.7–2.9 万条 | 点击即跳 |
| 书签根 | Page tree / Page list / Device tree / Device tag list | 四个入口 |

> ROCH 的 PDF 用德语书签：Seitenbaum / Seitenliste / Betriebsmittelbaum / Betriebsmittelliste。含义相同。

## B 第一跳：电位箭头（跨页电源）
```flow LR
(第 9 页 -10L1.1 / 51.0) -> (第 15 页 -10L1.1 / 10.3)
(第 15 页 =LVS 主配电) -> (第 17 页 主接触器)
```
| 起点 | 标记 | 跳到 | 反跳 |
|---|---|---|---|
| ANWEN p.9 主进线 | `-10L1.1 / 51.0` | p.15 `=LVS/51` | p.15 顶部 `-10L1.1 / 10.3` |
| ANWEN p.9 PE | `-XPE / 12.1` | p.10 `=MPS/12` | 同页返回 |
| ANWEN p.22 24V | `-24VDC / 106.0` | p.23 `=DCV/106` | p.23 `-24VDC / 105.6` |

> 箭头方向记法：信号名在前是“去”，页号在前是“来自”。两边都能点。

## E 第四跳：PLC 三方互跳
```flow LR
(电路页 -405A1-K104) -> (PLC 总览 p.48)
(电路页 &PLCV/104.4) -> (PLCV 页 p.117)
(PLCV p.110 通道 I200.0) -> (安全页 p.39)
```
| 点击位置 | 落到 | 看到什么 |
|---|---|---|
| p.17 卡号 `-405A1-K104` | p.48 `=PLC/405` | 整站模块排列 |
| p.17 `&PLCV/104.4` | p.117 `&PLCV/104` | 该卡 16 通道表 |
| p.48 `-405A1-K10` | p.110 `&PLCV/10` | EL1918 安全通道 |
| p.110 `DI0 / I200.0` | p.39 `=STE/321` | 安全门电路 |

> 同一行信号有三处落点：电路、PLCV、程序。核对时三处都要对。

## G 一份图纸的四棵树
| 书签 | 结构 | 什么时候用 |
|---|---|---|
| Page tree | 文档→功能→功能组→柜→页 | 按章节顺序读图 |
| Page list | 全部页平铺 | 已知页名快速跳 |
| Device tree | 结构→柜→字母→设备 | 已知器件找所有页 |
| Device tag list | 全部标签平铺 | 查重名、查旧标签 |

> 复制页后改标签，用 Device tag list 查旧标签是否清零。

## H 新平台页树差异
| 平台 | 结构标识 | 报表 |
|---|---|---|
| 旧 Beckhoff（DALIAH 等） | `==GEN` `==HQ1/2` | PLCV、BUSV、WRE、LAY、CON |
| 新 EU（ADARA/BELEN/ROCH） | 增加 `=TPS` `=SOV` `=POT` `=HQ` `=LDC` `=STA` | 增加 MAV、DEV、PLG |
| SQ-M（VELJANA 等） | `=LSV` 替代 `=LVS` | 同上，无 MAV/DEV |
| SQ-N 单柜（ATARA） | 只有 `+13511` | 无 WEV、无 CMC |

> 新平台多出 `&MAV` 机器总览与 `&DEV` 器件接线图。别按旧项目找这两类报表。

## I 常见坑
| 现象 | 原因 | 处理 |
|---|---|---|
| 页码对不上 | 图框页号 ≠ PDF 页码 | 以图框页号为准 |
| 点了不跳 | 阅读器禁用链接 | 换 PDF 阅读器 |
| 找不到器件 | 只翻电路页 | 用 Device tag list |
| 双刀只看到 HQ1 | 页树没展开 `==HQ2` | 找第二个 `==HQ2` |
| 列号写成 1–10 | 图框是 0–9 | 按 0–9 读 |
| 报表行回不到电路 | Sheet 列为空 | 器件缺主功能页 |
