`BOM/` 现有 22 份 SAP 导出 BOM，行数 22–4473。`Data` sheet 按层级缩进，不是平表。电气物料集中在 B 列以 E 或 I 开头的分支下面；只看顶层会漏掉 90% 的电气件。本页用 3 个历史项目（DALIAH/ANWEN/AZARIA）讲读法，全量覆盖与冲突见 [43 三方核对](43-bom-crosscheck.html)。

## A 这份文件是什么
| 项 | 内容 |
|---|---|
| 文件名 | `<订单号>.xlsx`；3401 是订单行项目 |
| 来源 | SAP BOM 导出 |
| sheet | `Data` |
| 表头行 | 第 9 行 |
| 数据行 | 第 10 行起 |
| 首行 | `Sales Order /Item`、`Plant/Usage/Alt.`、`Description`、`Base Qty`、`Reqd Qty` |
| 用途 | 采购、生产、成本、备件、电气核对 |

## B 20 列怎么分组
| 组 | 列 | 读法 |
|---|---|---|
| 层级 | Explosion level | `.1`、`..2`、`...3`…点越多层级越深 |
| 物料 | Component number | 物料号/组件号；E/I 开头是电气分支 |
| 描述 | Object description | 英文物料描述 |
| 类别 | Item category | L / Y / R 等行类别 |
| 规格 | Size/dimensions | 尺寸/规格 |
| 数量 | Comp. Qty (CUn)、Component UoM | 数量与单位（PC/M/KG） |
| 生产 | Production relevant | X 表示生产相关 |
| 行号 | Item Number | 分支内序号 0010/0020… |
| 备件 | Spare Part Indicator | 备件标识 |
| 状态 | Plant-Specific Material Status | 50 / 95 等状态码 |
| 采购 | Special Procurement Type | 50 等采购类型 |
| 排序 | Sort String、Colour Code | 排序与颜色码 |
| 工厂 | Plant、Base Unit、MRP Type、Valid from | 工厂 1100/6100、基本单位、MRP 类型、有效期 |

> L/Y/R、50/95、PD/ND 的精确 SAP 含义以主数据为准。可以确定的是：`R` 行常按 KG 计量（板材/原材料），`L` 行多为库存件，`Y` 行多为图纸/非库存件。

## C 层级怎么读
```tree
.1 SH42CO0011 BASIC MACHINE
  ..2 851250087 BASIC MACHINE AB3350
    ...3 851249740 STEEL FRAME AB 3150/3350
      ....4 851237885 STEEL FRAME AB 3150/3350
  ..2 E042CO0001 ELECTRICAL COMPONENTS
    ...3 851154824 CABLE 4X2X0,5MM²
    ...3 851152127 SERVOMOTOR 5.8KW
  ..2 E_13511 E_13511
    ...3 ...
```

| 规则 | 说明 |
|---|---|
| 点数=层级 | `.1` 顶层，`..2` 第二层，`...3` 第三层 |
| 父行是装配 | 父行数量通常为 1，子行是实际物料 |
| 子行缩进 | 子行紧跟父行，直到下一个同级或更高级 |
| 同一物料可重复 | 不同分支下同一物料号可出现于多个分支，数量分别计算 |

## G 用 BOM 核对图纸与 SV
```flow LR
SV特征 --> 电气分支
电气分支 --> 子物料
子物料 --> 图纸设备标签
图纸设备标签 --> 位号/页号
```

| 步骤 | 做什么 | 例子 |
|---|---|---|
| 1 | 先看 `.1` 顶层，确认整机分段 | BASIC MACHINE / DRIVE / INFEED / DISCHARGE |
| 2 | 找 E/I 分支，判断柜号组 | 阿联酋 E_13505/15/25/45；山东 E_13501/11/31/41；新 SQ-M 13515/13545；新 HQ-M 13501 组 |
| 3 | 展开分支，数关键件 | 伺服电机、驱动、PLC、安全模块 |
| 4 | 用物料描述对图纸位号 | SERVOMOTOR 112kW ↔ `-1300M1/M2` |
| 5 | 用 SV 反查选配 | Splice Detection=Yes ↔ 拼接传感器/电缆 |

## H 常见错误
| 错误 | 后果 | 正确做法 |
|---|---|---|
| 只数 E/I 顶层 20 行 | 以为电气只有 20 个件 | 展开直接子行：阿联酋 763 行 |
| 把 E_135xx 整包当电气 | 混入柜体五金 | 看子项描述，区分电气/机械 |
| 忽略 R 行按 KG | 数量级错 | 看 UoM：M/KG vs PC |
| 同一物料号只算一次 | 数量少算 | 同一物料在不同分支分别计数 |
| 忽略 Valid from | 用了过期物料 | 核对有效期与工厂 |
| 拿 3401 当唯一依据 | 与图纸不一致 | BOM 与图纸、SV 三方核对 |
| 只看 E/I 分支 | 漏掉机械分支下的传感器/接近开关 | 传感器也可能挂在机械分支，按描述搜 SENSOR/SWITCH |

> ATARA 与 AUDRIC 两份 BOM 未展开（22/29 行），不能用于核对。
