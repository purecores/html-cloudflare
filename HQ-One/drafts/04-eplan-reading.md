一套 HQ 图纸 200–370 页。不要从第 1 页翻到最后一页。先读封面和图框，再用“四棵树”定位，最后用交叉引用追信号。

## A 先读封面和图框
| 字段 | AISLING 示例 | 用途 |
|---|---|---|
| Sales order | 20531783 | 对应 SAP 销售订单 |
| Item | 3401 | 订单行项目，SAP BOM 也用 3401 |
| Drawing number | 855790 | 图号，文件名之外的第二标识 |
| Project description | SQ-M+ (cut off) | 机型与设备范围 |

## B 四棵树：PDF 书签的四个入口
| 书签 | 内容 | 什么时候用 |
|---|---|---|
| Page tree | 按功能组/柜号/页号组织的页树 | 按系统章节顺序读图 |
| Page list | 全部页面的平铺清单，页名含完整结构标识 | 已知页名，快速跳页 |
| Device tree | 按结构标识→柜号→设备类别→设备标签→表示类型组织的设备树 | 已知器件，找它出现在哪些页 |
| Device tag list | 全部设备标签的索引，带页号 | 查一个设备的所有出现位置 |

```flow LR
(封面/图框) --> Page tree
(封面/图框) --> Page list
(封面/图框) --> Device tree
(封面/图框) --> Device tag list
Page tree --> 电路页
Device tree --> 电路页
Device tree --> 布置图
Device tag list --> 电路页
```

| 页名第一段 | 文档类型 | 内容 | 典型页 |
|---|---|---|---|
| `&GEN` | 通用信息 | 封面、机器代号表、线径/颜色、铭牌 | PDF 2–8 |
| `&WDA` | 电路图 | 主回路、控制回路、安全回路 | EPLAN 10 / PDF 9 |
| `&PLCV` | PLC 通道图 | 每张卡一页，地址+信号+去向 | PLCV 202 / PDF 126 |
| `&BUSV` | 网络总览 | EtherCAT/Ethernet/Drive-CLiQ | BUSV 1 / PDF 131 |
| `&WRE` | 电缆图 | 外部/内部电缆清单 | WRE 10 / PDF 134 |
| `&LAY` | 布置图 | 柜体布置、箱柜设备清单（BOM） | LAY 20 / PDF 145 |
| `&CON` | 端子图 | 每柜端子排、端子清单 | CON 2 / PDF 165 |
| `&PLG` | 插头图 | 仅 KQ-M，插头/针脚 | PDF 78 |

> 各文档块的回路级深读：PLCV → [18 PLC/IO](18-plc-io.html)；WRE/CON/LAY → [22 端子/电缆](22-terminals-cables.html)；DEX → [21 整线接口](21-dex-interface.html)。
>
> 这套图没有独立的“部件清单”报表页。BOM 在 `&LAY` 的“箱柜设备清单”页，表头是 `DT designation | Position | Part number | function text | Sheet | Type | Safety relevant`。按柜号找：AISLING 的 +13501 在 PDF 145–147，+13511 在 150–154，+13531 在 156–159。

## C 结构标识怎么读
以 `&WDA==GEN=MPS+13501 HQ/10 Main Power Supply` 为例：

| 片段 | 含义 |
|---|---|
| `&WDA` | 文档类型：Circuit diagram 电路图 |
| `==GEN` | 位置：Generally 通用部分 |
| `=MPS` | 功能组：Main Power Supply 主供电 |
| `+13501` | 柜号：Switch cabinet 1 |
| `HQ/10` | 设备/页号：第 10 页；列号 0–9，不是 1–10 |
| `Main Power Supply` | 页标题 |

设备标签 `=MPS+13501 HQ-XPE:1:a;d` 再拆一层：

| 片段 | 含义 |
|---|---|
| `=MPS+13501` | 功能组 + 柜号 |
| `HQ-XPE` | 设备标签：X 表示端子排，PE 表示接地端子 |
| `:1` | 端子排内的第 1 个端子 |
| `:a;d` | 端子连接/芯线标识 |

## E 设备标签与代号
| 代号 | 典型含义 | 例子 |
|---|---|---|
| Q | 断路器、隔离开关、保护开关 | `-10Q1` 主开关 |
| F | 熔断器、热保护、监视继电器 | `-F3` |
| K | 接触器、继电器 | `-K21` |
| M | 电机 | `-M1` 主传动电机 |
| X | 端子排 | `-XPE` 接地端子、`-X24V` |
| T | 变压器、电源 | `-T1` |
| S | 按钮、开关、限位 | `-S3` |
| U | 变频器/驱动/电源模块 | `-10U3` |
| WC | 电缆 | `WC560` |

> 设备标签前的数字通常是页号（`-10Q1` 表示第 10 页的 Q1）。这是 EPLAN 的“页号前缀”约定，便于从标签反查页。
>
> 例外：端子 `-X…` 按功能命名（`-XPE`、`-X24V`），电缆 `-W…` 按类型+去向/流水号命名（`-WC461`、`-WP13001`），都不遵守页号前缀。

## F 交叉引用：从一页跳到另一页
设备树的一条记录：

```text
-MPS +13501
  Q
    -10Q1
      Multi-line   1;2;3;4;5;6    &WDA==GEN=MPS+13501 HQ/10.1
      Panel layout                &LAY==HQ1=LAY+13501 HQ/10.2
```

读法：
1. `Multi-line` 表示多线电路图，`1;2;3;4;5;6` 是触点/线圈的列号。
2. `/10.1` 表示第 10 页第 1 列。
3. `Panel layout` 表示同一器件的柜内布置图，页号 `/10.2` 是布置图页。
4. 图纸页上的 `→ /15.3` 或 `← /10.1` 是跨页交叉引用，直接跳到对应页/列。

## G 追一条急停链
```flow LR
(现场急停) -> 端子X
端子X -> 安全输入EL1904
安全输入EL1904 -> 安全PLC/EL1918
安全PLC/EL1918 -> 安全输出EL2904
安全输出EL2904 -> 主传动STO
```

| 步骤 | 在哪找 | 看什么 |
|---|---|---|
| 1. 现场急停 | `=STE` 安全页 | 急停按钮、门开关的端子号 |
| 2. 进柜 | `=STE` + 柜号 | 端子排、芯线号、电缆号 |
| 3. 安全输入 | `=PLC` 页 + IO 表 | EL1904 通道地址（如 4DI_I201） |
| 4. 安全逻辑 | `=PLC` 安全程序页 | 双通道、复位、互锁 |
| 5. 安全输出 | `=PLC` / `=STE` | EL2904 输出到 STO 端子 |

> IO 表中的 `4DI_I201` 与图纸中的 EL1904 模块一一对应。先在 IO 表找到信号，再回图纸找端子和电缆。

## I 常见坑
| 现象 | 原因 | 处理 |
|---|---|---|
| 页码对不上 | 图框页号 ≠ PDF 页码 | 以图框页号为准，PDF 页码另注 |
| 找不到器件 | 只翻了电路图，没看设备树 | 用 Device tree 或 Device tag list |
| 同一器件出现在布置图 | 设备树有 Panel layout 分支 | 布置图页号在 `&LAY` 下 |
| 双刀项目只看到 HQ1 | 页树没展开 `==HQ2` | 在 Page tree 里找第二个 `==HQ2` |
| 书签写 13505/13545/13515 | SQ-M+ 模板的旧柜号残留，与结构 +13501/+13511/+13531 不是一一对应 | 以 `+` 结构标识和页码为准 |
| 列号写成 1–10 | 图框顶边列号是 0–9 | `/10.1` 表示第 10 页第 1 列 |
| 设备标签带页号前缀 | EPLAN 页号前缀约定 | `-10Q1` 在第 10 页 |
