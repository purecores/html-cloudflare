| 符号 | 含义 A | 含义 B | 区分方法 |

| $p$ | 极对数 | 功率的另一种写法 | 功率通常写 $P$ |
| $T$ | 转矩 $T_e$ | 温度、时间常数 $T_r$ | 看下标与单位 |
| $L$ | 电感，H | 叠长，m | 看单位 |
| $B$ | 磁密，T | 阻尼系数 $B_\omega$ | 看单位与下标 |
| $A$ | 面积，m² | 电负荷，A/m | 看单位 |
| $J$ | 转动惯量，kg·m² | 电流密度，A/mm² | 看单位 |
| $\delta$ | 气隙长度 | 功角 | 设计上下文 vs 同步机上下文 |
| $\beta$ | 线圈节距比 | 电流角 | 绕组上下文 vs 控制上下文 |
| $\sigma$ | 切向应力 | 漏磁系数 | 设计上下文 vs 异步机上下文 |
| $\lambda$ | 磁链 | 特征值、波长 | 电机上下文通常是磁链 |
| $\psi$ | 磁链 | 功角？ | 功角通常用 $\delta$ |
| $\Phi$ | 磁通 | 功率因数角 $\varphi$ | 大小写不同 |
| $\omega_e$ | 电角速度 | 电网角频率 | 同步机中两者常相等 |
| $\omega_s$ | 机械同步角速度 | 定子电角频率 | 看是否除以 $p$ |
| $\omega_r$ | 机械转子角速度 | 转子电角速度 | 看是否乘 $p$ |
| $K_p$ | 比例增益 | 节距因数 $k_p$ | 大小写不同 |
| $q$ | 每极每相槽数 | 电荷 | 电机上下文是槽数 |
| $m$ | 相数 | 质量 | 看单位与上下文 |
| $n$ | 转速 | 谐波次数 | 看单位与下标 |
| $f$ | 频率 | 摩擦 | 摩擦通常写 $F_f$ |
| $I_f$ | 励磁电流 | 特征电流 $I_{ch}$ | 看下标 |

### 读公式的三步法

1. **看坐标系与变换约定**：abc、αβ、dq？幅值不变还是功率不变？
2. **看峰值还是有效值**：转矩公式多用峰值；铭牌多用有效值。
3. **看单位与量纲**：电角度还是机械角度？单相还是三相？每极还是每相？

**一句话**：公式本身不难。难的是公式背后的约定。约定错了，数就全错。

| 场景 | 系数 | 说明 |

| 功率不变 Park | $1$ | 转矩公式不带 $3/2$ |
| 正弦电势 | $4.44$ | $E=4.44fNk_w\Phi_m$ |
| 方波电势 | $4.0$ | 波形因数不同 |

## B 学习路径与自检


### 一条不走弯路的顺序

| 阶段 | 学什么 | 目标 | 建议时间 |
| --- | --- | --- | --- |
| 1 | 磁路、磁链、能量法 | 知道转矩从哪来 | 3~5 天 |
| 2 | 三相系统、Clarke/Park | 看懂 dq 语言 | 3~5 天 |
| 3 | 三大转矩门派 | 分清同步、异步、磁阻 | 2~3 天 |
| 4 | 同步机调速、V/f、弱磁 | 理解频率与磁通 | 1 周 |
| 5 | 异步机转差、T-s、双馈 | 理解转差与滑差功率 | 1 周 |
| 6 | FOC、DTC、三环、SVPWM | 看懂控制信号链 | 1~2 周 |
| 7 | 反电势、谐波、齿槽 | 理解波形与脉动 | 1 周 |
| 8 | 设计方程、公差、成本 | 理解设计与制造 | 1~2 周 |

**顺序原则**：先本体，后控制。先能量，后信号。先公式，后参数。

### 如果只记十句话

1. 转矩来自磁场与电流的乘积。
2. 同步机转速被频率锁死；异步机靠转差感应。
3. 变频器是地板；FOC 与 DTC 是并列策略。
4. 三环是套娃；内环快，外环慢。
5. dq 是把交流旋成直流的眼镜。
6. 反电势波形由本体决定；控制器改不了。
7. 5、7 次反电势谐波变成 6 倍频转矩脉动。
8. 弱磁就是注负 $i_d$，抵消永磁磁链。
9. 设计是标称值加公差，不是一堆孤立数字。
10. 全生命周期里，电费是大头；采购价只是零头。

### 读一张铭牌

以一台 11 kW 异步机为例：

| 铭牌项 | 数值 | 含义 |
| --- | --- | --- |
| $P_N$ | 11 kW | 额定输出功率 |
| $U_N$ | 380 V | 额定线电压 |
| $I_N$ | 21.5 A | 额定线电流 |
| $f_N$ | 50 Hz | 额定频率 |
| $n_N$ | 1460 r/min | 额定转速 |
| $\cos\varphi$ | 0.84 | 额定功率因数 |
| $\eta$ | 89% | 额定效率 |
| 接法 | Y | 定子绕组接法 |
| IP55 | 防护等级 | 防尘防水 |
| F 级 | 绝缘等级 | 允许温升 |
| S1 | 工作制 | 连续运行 |

**先算三件事**：

$$ n_s=\frac{60f_N}{p}=\frac{60\times50}{2}=1500\ \mathrm{r/min} $$

$$ s_N=\frac{1500-1460}{1500}=0.0267 $$

$$ T_N=9550\frac{P_N}{n_N}=9550\frac{11}{1460}=71.9\ \mathrm{N\cdot m} $$

**再算转差功率**：

$$ P_{ag}=\frac{P_m}{1-s}\approx\frac{11}{0.9733}=11.30\ \mathrm{kW} $$

$$ P_{cu,r}=sP_{ag}=0.0267\times11.30=0.302\ \mathrm{kW} $$

$$ f_r=sf_s=0.0267\times50=1.33\ \mathrm{Hz} $$

**读法**：额定点转差很小。转子铜耗约 0.3 kW。转子频率只有 1.33 Hz。这就是异步机额定点效率高的原因。

### 三十分钟估算一台永磁同步机

**需求**：10 kW，3000 r/min，初步选 $D=L=0.10\ \mathrm{m}$，切向应力 $\sigma=20\ \mathrm{kPa}$。

**第一步：转矩**：

$$ T=9550\frac{P}{n}=9550\frac{10}{3000}=31.8\ \mathrm{N\cdot m} $$

**第二步：输出方程**：

$$ T=\frac{\pi}{2}D^2L\sigma=\frac{\pi}{2}\times0.01\times0.10\times20000=31.4\ \mathrm{N\cdot m} $$

结果与需求接近。尺寸假设合理。

**第三步：电频率**。取 8 极，$p=4$：

$$ f=\frac{pn}{60}=\frac{4\times3000}{60}=200\ \mathrm{Hz} $$

**第四步：机械角速度**：

$$ \omega_r=\frac{2\pi n}{60}=314.2\ \mathrm{rad/s} $$

**第五步：功率复核**：

$$ P=T\omega_r=31.8\times314.2=9.99\ \mathrm{kW} $$

**说明**：这是初步估算。实际设计还要校核磁路、热、绝缘、转子强度与效率 Map。切向应力 20 kPa 是液冷电机的典型量级。

### 十二个自检问题

| 问题 | 一句话答案 |
| --- | --- |
| 同步机为什么没有自起动转矩？ | 转差不为零时，功角持续累积，平均转矩为零 |
| 异步机为什么必须有转差？ | 没有相对运动，就没有感应电流，也没有转矩 |
| 为什么基频以下要保持 $U/f$ 恒定？ | 保持磁通恒定，避免铁芯饱和 |
| 为什么弱磁要注负 $i_d$？ | 用直轴电枢反应抵消永磁磁链，降低电压需求 |
| 5、7 次谐波为什么变成 6 倍频脉动？ | 与基波电流相乘后，和频与差频在三相中合成 6 次 |
| BLDC 与 PMSM 是两类物理拓扑吗？ | 不是；同一拓扑，反电势波形是连续谱 |
| FOC 与 DTC 的分水岭是什么？ | 有无电流环与坐标解耦 |
| 观测器为什么低速不准？ | 反电势幅值随转速下降，信噪比变差 |
| 100 个参数是 100 个旋钮吗？ | 不是；是设计数据全集，独立优化变量通常不到 10 个 |
| BOM 占比高等于制造简单吗？ | 不等于；难在一致性、公差与批次控制 |
| SVPWM 为什么比 SPWM 高 15.5%？ | 零序注入把线性区扩展到六边形内切圆 |
| 绕线转子为什么能串阻调速？ | 转子多一个电端口，转差功率可以管理 |

### 下一步可以深挖的六个方向

1. **电磁场有限元**：JMAG、Maxwell、Motor-CAD。看磁密云图、反电势、齿槽转矩、效率 Map。
2. **热与冷却**：热网络、CFD、水套、油冷、喷淋。连续转矩的瓶颈通常在这里。
3. **无传感器控制**：高频注入、SMO、EKF、MRAS。低速与零速是难点。
4. **NVH**：电磁力阶次、结构模态、共振、噪声。转矩脉动只是源头之一。
5. **可靠性与寿命**：绝缘老化、轴承电流、磁钢退磁、湿热循环。
6. **标准与认证**：IEC 60034、IE 效率等级、UL、CE、IP、绝缘等级。

### 收口

**本体决定能不能调、调哪个量。策略决定怎么把转矩凑出来。环决定谁管谁。零件只是可选插件。设计决定边界。成本决定能不能落地。**

这六句话，就是这座知识库的骨架。

### 材料与性能的耦合

- 高牌号硅钢：铁损低，价格高。
- 高矫顽力磁钢：耐温好，价格高。
- 薄硅钢：高频损耗低，叠压系数低。
- 高槽满率：铜耗低，工艺难。

**一句话**：材料不是「买回来装上」，它决定设计的边界。

## D 选型 checklist

### 需求

| 问题 | 为什么问 |
| --- | --- |
| 负载类型是什么？ | 恒转矩、风机、泵、惯性负载的转矩曲线不同 |
| 需要调速吗？ | 决定是否用变频器 |
| 调速范围多大？ | 决定弱磁与散热 |
| 连续转矩与峰值转矩？ | 决定电流与温升 |
| 工作制是什么？ | S1 连续、S2 短时、S3 周期 |
| 环境温度与海拔？ | 影响散热与绝缘 |
| 防护等级？ | IP 等级 |
| 电源条件？ | 电压、频率、相数 |
| 是否需要能量回馈？ | 决定整流类型 |
| 噪声与振动限值？ | 决定本体与控制 |
| 寿命与维护？ | 决定轴承与冷却 |
| 目标成本？ | 决定材料与工艺 |

### 电机类型

| 需求 | 优先方案 |
| --- | --- |
| 高效率、宽调速 | PMSM + FOC |
| 低成本、风机泵 | 异步机 + 变频 |
| 大起动转矩 | 绕线转子、双笼、变频 |
| 高速 | PMSM、感应机、护套转子 |
| 高温 | 电励磁、钐钴、异步 |
| 免维护 | 鼠笼、永磁 |
| 大功率 | 同步机、异步机、多电平 |

### 控制与反馈

- 是否需要位置控制？需要编码器或旋变。
- 是否需要低速大转矩？需要编码器或高频注入。
- 是否需要能量回馈？需要有源前端。
- 是否需要安全功能？STO、安全编码器。

## E 故障排查表

| 现象 | 可能原因 | 检查 |
| --- | --- | --- |
| 过流 | 负载过大、堵转、短路、参数错 | 电流波形、绝缘、负载 |
| 过压 | 减速过快、回馈能量、母线电容小 | 制动电阻、减速斜坡 |
| 过热 | 冷却不足、过载、谐波、风道堵 | 温度、流量、电流 |
| 振动 | 不平衡、对中不良、轴承、共振 | 频谱、动平衡、地脚 |
| 噪声 | 电磁力、齿槽、轴承、风噪 | 阶次分析、断电对比 |
| 失步 | 过载、加速太快、弱磁不足 | 功角、电流、电压 |
| 退磁 | 高温、过流、反向磁场 | 反电势、磁钢温度 |
| 编码器报警 | 污染、线缆、干扰 | 信号、屏蔽、接地 |
| 轴承电流 | 共模电压、接地不良 | 轴电压、绝缘轴承 |
| 通讯中断 | 干扰、终端电阻、线序 | 屏蔽、波特率、接线 |

### 快速定位

1. **断电盘车**：判断机械卡滞。
2. **空载运行**：判断电磁与控制。
3. **加载运行**：判断热与电流。
4. **看波形**：电流、电压、反电势。
5. **做阶次分析**：定位振动与噪声源。
